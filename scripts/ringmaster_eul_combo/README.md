## Что умеет

Запускает прокаст по врагу у курсора: при необходимости врывается с Blink, поднимает цель в Eul, заряжает кнут к приземлению, затем отправляет колесо за спину и продолжает контроль предметами.

- рассчитывает заряд кнута по времени падения из Eul и пингу
- после страха направляет колесо за спину цели
- использует предметы и Hex для продолжения контроля

## Установка

1. Поместите `ringmaster_eul_combo.lua` и `!_qLocalizer.lua` в `Umbrella\scripts`.
2. Перезагрузите скрипты и откройте настройки Ringmaster → Eul Combo.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Ringmaster Eul Combo (English)

## What it does

Runs a combo on the enemy near the cursor: blinks in when needed, lifts the target with Eul, times a fully charged whip for landing, then sends the wheel behind the target and extends control with items.

- times whip charge using Eul landing time and ping
- sends the wheel behind the target after the fear
- uses items and Hex to extend control

## Install

1. Place `ringmaster_eul_combo.lua` and `!_qLocalizer.lua` in `Umbrella\scripts`.
2. Reload scripts and open Ringmaster → Eul Combo settings.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
