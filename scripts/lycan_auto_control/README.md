## Что умеет

Автоматически распределяет волков Lycan для продвижения по линии, а юнитов под контролем через Dominator — для фарма леса и использования способностей.

- волки продвигают ближайшую линию
- подконтрольные через Dominator существа фармят лес и используют способности

## Установка

1. Поместите `lycan_auto_control.lua` в `Umbrella\scripts`.
2. Перезагрузите скрипты и настройте поведение подконтрольных юнитов.

# Lycan Auto Control (English)

## What it does

Automatically assigns Lycan's wolves to push a lane and units controlled with Dominator to farm the jungle and use their abilities.

- wolves push the nearest lane
- units controlled through Dominator farm the jungle and cast abilities

## Install

1. Place `lycan_auto_control.lua` in `Umbrella\scripts`.
2. Reload scripts and configure controlled-unit behavior.
