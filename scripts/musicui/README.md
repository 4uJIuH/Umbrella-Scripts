# MusicUI (English)

## What it does

A Lua overlay plus MusicUI.exe: the app reads Spotify and the Windows player, the overlay draws it in game. The author distributes releases on <a href="https://but3rflys.github.io/umbrella-work/#/" target="_blank" rel="noopener">Umbrella Work</a>.

- track, cover art and progress in game
- equalizer driven by the real audio
- lyrics scrolling with the song
- playback controls from the overlay
- Spotify and the Windows system player

## Install

1. Download `MusicUI.rar` from the latest release and unzip it.
2. Put `MusicUI.lua` into the `scripts` folder next to your cheat.
3. Run `MusicUI.exe` and follow the prompts in the console.
