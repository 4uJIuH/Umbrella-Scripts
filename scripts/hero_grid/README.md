# Hero Grid

Loads custom Dota 2 hero-grid configurations from JSON files.

Author: ! M0RC1 (Discord: wh1teray)

## Install

The Script Manager Install button downloads `hero_grid.lua` and three sample grid files directly into `umbrella\scripts`; it does not install a ZIP archive.

1. Install Hero Grid from Script Manager.
2. Reload Lua scripts.
3. Open `Changer → Main → Сетки`.
4. Enter a JSON filename, such as `shiffer.json`, and click `Загрузить сетку`.

The included samples are `code_geas.json`, `shiffer.json`, and `shizuku.json`. Additional grids can be placed in the scripts folder or in `scripts\hero-grid`.

More grids: [GridStudio Workshop](https://gridstudio.me/workshop).

Some grids may have minor visual anomalies.
