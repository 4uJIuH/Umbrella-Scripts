## Что умеет

Hero Grid добавляет в меню Dota 2 загрузчик пользовательских сеток героев. Можно выбрать JSON-файл, создать конфигурацию сетки и сразу применить её. Автор: ! M0RC1 (Discord: wh1teray).

- Загружает сетку из JSON-файла и применяет её без перезапуска игры
- В поставку включены три примера сеток: code_geas.json, shiffer.json и shizuku.json
- Поддерживает пользовательские файлы в корне scripts, а также в папках hero-grid и hero_grid

## Установка

1. Нажмите «Установить» в Script Manager: он загрузит `hero_grid.lua` и три JSON-примера непосредственно в `umbrella\scripts` (без ZIP-архива).
2. Перезагрузите Lua-скрипты.
3. Откройте `Changer → Main → Сетки`, укажите имя файла с расширением `.json` (например, `shiffer.json`) и нажмите «Загрузить сетку».
4. Другие сетки можно разместить в корне `scripts` или в папке `scripts\hero-grid` и выбрать по имени.

# Hero Grid (English)

## What it does

Hero Grid adds a Dota 2 menu for loading custom hero-grid configurations. Select a JSON file to create and apply its grid without restarting the game. Author: ! M0RC1 (Discord: wh1teray).

- Loads and applies a hero grid from a JSON file without restarting the game
- Includes three sample grids: code_geas.json, shiffer.json, and shizuku.json
- Supports custom files in the scripts root and in hero-grid or hero_grid folders

## Install

1. Click Install in Script Manager to download `hero_grid.lua` and three sample JSON files directly into `umbrella\scripts` (no ZIP archive).
2. Reload the Lua scripts.
3. Open `Changer → Main → Сетки`, enter a filename including `.json` (for example, `shiffer.json`), and click `Загрузить сетку`.
4. Place other grids in the scripts root or `scripts\hero-grid`, then select them by filename.
