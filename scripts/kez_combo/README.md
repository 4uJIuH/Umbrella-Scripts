## Что умеет

Дополнительный комбо-скрипт Kez. Автор предупреждает, что код экспериментальный и может требовать доработки.

- автоматизирует комбинации способностей Kez
- экспериментальная версия
- основное комбо Umbrella отключать не нужно

## Установка

1. Поместите `kez_combo.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты; основное комбо Umbrella оставьте включённым.

# Kez Combo (English)

## What it does

An additional Kez combo script. The author notes that the code is experimental and may need further work.

- automates Kez ability combos
- experimental version
- you do not need to disable Umbrella's main combo

## Install

1. Place `kez_combo.lua` in `Umbrella\scripts`.
2. Reload scripts; keep Umbrella's main combo enabled.
