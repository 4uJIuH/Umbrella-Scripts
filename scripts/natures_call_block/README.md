## Что умеет

Размещает деревья, созданные Nature's Call, рядом с выбранным врагом, чтобы ограничить его перемещение. Доступны автоматический режим и применение по бинду, а также настройки смещения.

- Размещение деревьев рядом с выбранной целью
- Автоматический режим или активация по бинду
- Настройка смещения точки блокировки

## Установка

1. Поместите `NaturesCallBlock.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Nature's Prophet → Nature Call Block`.

# Nature's Call Block (English)

## What it does

Places trees created by Nature's Call near a selected enemy to restrict their movement. Choose automatic activation or a keybind and configure the placement offset.

- Places trees near a selected target
- Automatic mode or keybind activation
- Configurable block position offset

## Install

1. Place `NaturesCallBlock.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Nature's Prophet → Nature Call Block`.
