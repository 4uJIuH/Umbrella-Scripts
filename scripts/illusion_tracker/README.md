## Что умеет

Определяет появление копий, связывает отдельные иллюзии с группами по выбранным клавишам и рисует метки.

- Отслеживает появление иллюзий от Manta Style и других источников
- Показывает цветные круги и клавиши групп над юнитами
- Автор предупреждает, что одна настройка в меню не работает

## Установка

1. Поместите `IllusionTracker.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты. Настройки: Основное → IllusionTracker.

# Illusion Tracker (English)

## What it does

Detects spawned copies, associates individual illusions with chosen key groups, and draws indicators.

- Tracks illusions created by Manta Style and other sources
- Displays colored circles and group keys above units
- The author notes that one menu option does not work

## Install

1. Place `IllusionTracker.lua` in `umbrella\scripts`.
2. Reload the Lua scripts. Settings: Main → IllusionTracker.
