## Что умеет

Находит союзника под Tether и применяет Overcharge при использовании его ключевой способности.

- Порог маны и настраиваемая задержка реакции
- Опциональная проверка боя и радиуса врагов
- Проверяет, что Io не оглушён и не заглушён
- Отдельные настройки в Heroes → Io → Overcharge

## Установка

1. Поместите `io_overcharge.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте Heroes → Hero List → Io → Overcharge.

# Io Overcharge (English)

## What it does

Finds the ally connected by Tether and casts Overcharge when that ally uses a tracked key ability.

- Mana threshold and configurable reaction delay
- Optional combat and enemy-radius checks
- Checks that Io is not stunned or silenced
- Settings under Heroes → Io → Overcharge

## Install

1. Place `io_overcharge.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open Heroes → Hero List → Io → Overcharge.
