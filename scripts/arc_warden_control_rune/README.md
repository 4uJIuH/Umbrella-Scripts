## Что умеет

По бинду перемещает Арка Вардена и Темпест-Дабла к руне и применяет Magnetic Field с учётом уровня способности.

- Управляет героем и клоном по одной клавише
- Учитывает уровень второго умения при расчёте применения
- Настраиваемый режим бинда: удержание или переключение

## Установка

1. Поместите `arc_warden_control_rune.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Arc Warden → Контроль Рун`.

# Arc Warden Control Rune (English)

## What it does

On a keybind, moves Arc Warden and Tempest Double to a rune and casts Magnetic Field based on the ability's level.

- Controls the hero and clone with one key
- Accounts for the second ability's level when timing the cast
- Configurable hold or toggle keybind

## Install

1. Place `arc_warden_control_rune.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Arc Warden → Контроль Рун`.
