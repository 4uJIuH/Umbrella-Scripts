## Что умеет

Визуальный скрипт для старого оформления интерфейса игры.

- Настраивается через вкладку General → Main
- Может отличаться от текущего интерфейса после обновлений Dota

## Установка

1. Поместите `old_hud.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и проверьте настройки в General → Main.

# Old HUD (English)

## What it does

A visual script for an older version of the game's interface.

- Configured under General → Main
- May differ from the current interface after Dota updates

## Install

1. Place `old_hud.lua` in `umbrella\scripts`.
2. Reload the Lua scripts and review its settings under General → Main.
