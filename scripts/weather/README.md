## Что умеет

Косметический скрипт для смены визуальной погоды карты в Dota 2. Автор: ! M0RC1 (Discord: wh1teray).

- Выбор стандартного вида, зимы, дождя, сакуры, болота, осени, пустыни, весны, ада или северного сияния
- Меняет клиентскую переменную cl_weather

## Установка

1. Нажмите «Установить» в Script Manager или поместите weather.lua в umbrella\scripts.
2. Перезагрузите Lua-скрипты.
3. Откройте Changer → Main → Погода и выберите нужный вариант.

# Weather (English)

## What it does

A cosmetic script for changing the visual map weather in Dota 2. Author: ! M0RC1 (Discord: wh1teray).

- Select default weather, winter, rain, sakura, swamp, autumn, desert, spring, hell, or northern lights
- Changes the client-side cl_weather convar

## Install

1. Click Install in Script Manager or place weather.lua in umbrella\scripts.
2. Reload Lua scripts.
3. Open Changer → Main → Погода and select a weather effect.
