## Что умеет

Открытое приложение с графическим интерфейсом для переноса настроек Dota 2 между аккаунтами Steam. Перед переносом проверяет исходный аккаунт и может перезапустить Steam или Umbrella.

- находит Steam-аккаунты и проверяет наличие данных Dota 2
- позволяет выбрать исходный и целевой аккаунты
- исходный код и готовая сборка доступны в репозитории автора

## Установка

1. Скачайте Windows-приложение или исходный код из репозитория автора.
2. Проверьте источник и настройки перед переносом файлов аккаунта.

# SteamSync (English)

## What it does

An open-source GUI application for transferring Dota 2 settings between Steam accounts. It checks the source account before transfer and can restart Steam or Umbrella.

- discovers Steam accounts and checks for Dota 2 data
- lets you choose source and target accounts
- source code and a prebuilt application are available from the author's repository

## Install

1. Download the Windows application or source code from the author's repository.
2. Verify the source and transfer settings before moving account files.
