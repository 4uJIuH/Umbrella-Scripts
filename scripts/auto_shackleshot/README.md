## Что умеет

Скрипт для автоматического использования Shackleshot на Windranger.

- Автоматически находит вражеских героев, проверяет возможность связать и применяет Shackleshot
- Автоматический режим можно включить с заданной минуты игры
- Ручной режим применения при удержании кнопки
- Публикация скрипта: <a href="https://discord.com/channels/408315082439917578/1552753037259571301/1552754805103927438" target="_blank" rel="noopener">Discord</a>

# Auto Shackleshot (English)

## What it does

A script for automatically using Shackleshot on Windranger.

- Automatically finds enemy heroes, checks whether they can be shackled, and casts Shackleshot when possible
- Automatic mode can be enabled from a specified game minute
- Manual casting mode while holding a key
- Script post: <a href="https://discord.com/channels/408315082439917578/1552753037259571301/1552754805103927438" target="_blank" rel="noopener">Discord</a>

## Install

1. Place <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/auto-shackleshot-v1.0.0/Auto_Shackleshot.lua" target="_blank" rel="noopener"><code>Auto_Shackleshot.lua</code></a> in `umbrella\scripts`.
2. Place <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/q-localizer-v1.0.0/!_qLocalizer.lua" target="_blank" rel="noopener"><code>!_qLocalizer.lua</code></a> alongside it.
3. Reload the Lua scripts.
4. Open settings: `Scripts → Scripts → Auto Shackleshot`.
