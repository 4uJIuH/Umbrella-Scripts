# Invoker SS (English)

## What it does

A standalone module based on the Invoker framework by Discord user ID 393059037652058112. Its Sun Strike module was reworked by Discord user ID 316490958562787331; ChatGPT / OpenAI assistance is also credited. It includes target selection, prediction, Fog of War handling, Anti-Zigzag, portrait shots, and diagnostics. This is not a claim that the original framework was written from scratch.

- automatic Sun Strike with target selection and prediction
- manual portrait shots and Fog of War handling
- landing shots, Roshan/Tormentor steals, and Cataclysm support

## Install

1. Place `invoker_ss.lua` in `Umbrella\scripts` and reload Lua scripts.
2. Do not enable another script that also controls Invoker or Sun Strike.
