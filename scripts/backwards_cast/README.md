## Что умеет

Позволяет направлять некоторые способности с фиксированной дальностью, не разворачивая героя. Автор заявляет поддержку 37 способностей.

- Выбор способностей, для которых включён режим
- Без задержки при неподвижном герое; во время движения возможна задержка
- Поддерживает способности нескольких героев

## Установка

1. Поместите `backwards_cast.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте General → Main → Back Cast и включите Enable.

# Back Cast (English)

## What it does

Lets you aim selected fixed-range abilities without turning the hero. The author reports support for 37 abilities.

- Choose which abilities use the behavior
- No delay while standing still; casting while moving may be delayed
- Supports abilities across multiple heroes

## Install

1. Place `backwards_cast.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open General → Main → Back Cast and enable it.
