# Disable Tracker

считает время под разными эффектами контроля / tracks time spent under disabling effects

Последняя версия: [`v1.0.0` — `ugnetenie.lua`](https://raw.githubusercontent.com/4uJIuH/umbrella-scripts/main/scripts/disable_tracker/ugnetenie.lua)

<!-- releases:end -->

## Что умеет

Показывает, сколько времени герой провёл под оглушениями, безмолвием, обезоруживанием и другими дизейблами.

- Отслеживает несколько типов контроля и ограничений
- Показывает текущий эффект и сводную статистику
- Положение панели можно перемещать

## Установка

1. Поместите `ugnetenie.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Настройте индикатор в разделе General → Main → Oppression Indicator.

# Disable Tracker (English)

## What it does

Shows how long your hero has been affected by stuns, silences, disarms, and other disables.

- Tracks several types of disables and restrictions
- Shows the current effect and a summary
- The panel can be repositioned

## Install

1. Place `ugnetenie.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Configure the indicator under General → Main → Oppression Indicator.
