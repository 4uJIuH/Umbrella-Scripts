## Что умеет

Настраиваемый тренер для Ember Spirit с выбором и фиксацией цели, движением между противниками, комбо через ремнанты и системой побега. Автоматические приказы работают только на карте hero_demo_main; вне неё скрипт показывает заблокированный статус.

- Комбо с выбором цели, сближением, Flame Guard, Searing Chains и Sleight of Fist
- Предсказание перемещения и маршрута Fire Remnant
- Режимы танца между целями и настройки умного побега
- За пределами hero_demo_main не отправляет игровые приказы; Safe Mode может задерживать или блокировать действия

## Установка

1. Поместите `ember_spirit_sticky_trainer.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Ember Spirit Custom`.

# Ember Spirit Sticky Trainer (English)

## What it does

A configurable Ember Spirit trainer with target selection and locking, movement between enemies, Remnant-based combos, and an escape system. Automated orders are enabled only on the `hero_demo_main` map; elsewhere the script displays a blocked status.

- Combos with target selection, gap closing, Flame Guard, Searing Chains, and Sleight of Fist
- Movement prediction and Fire Remnant route planning
- Target-dancing modes and smart escape settings
- Sends no game orders outside `hero_demo_main`; Safe Mode may delay or block actions

## Install

1. Place `ember_spirit_sticky_trainer.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Ember Spirit Custom`.
