## Что умеет

Автоматически реагирует на запросы High Five, используя Темпест-Дабла. Может отвечать как своим союзникам, так и вражеским героям.

- Использует клона Arc Warden для ответа
- Реагирует на запросы от союзных и вражеских героев
- Автоматически обнаруживает доступную способность High Five

## Установка

1. Поместите `high_five.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Arc Warden → Arc Warden → Пятюня`.

# Arc Warden High Five (English)

## What it does

Automatically responds to High Five requests using Tempest Double. It can respond to both allied and enemy heroes.

- Uses Arc Warden's clone to respond
- Responds to requests from allied and enemy heroes
- Automatically detects when the High Five ability is available

## Install

1. Place `high_five.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Arc Warden → Arc Warden → Пятюня`.
