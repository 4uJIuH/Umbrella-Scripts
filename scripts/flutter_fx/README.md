## Что умеет

Показывает всплывающие значения урона и лечения для выбранных категорий юнитов. Настраиваются фильтры, шрифт, материалы, анимации и качество эффектов.

- Фильтры для своего героя, союзников, врагов, крипов и иллюзий
- Настройки отображения урона, лечения, промахов и критических эффектов
- Четыре режима качества, оформление и анимации

## Установка

1. Поместите `FlutterFX.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Combat Text FX → Flutter Combat`.

# FlutterFX (English)

## What it does

Displays floating damage and healing values for selected unit categories. Configure filters, fonts, materials, animations, and effect quality.

- Filters for your hero, allies, enemies, creeps, and illusions
- Options for damage, healing, misses, and critical effects
- Four quality modes, styling, and animations

## Install

1. Place `FlutterFX.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Combat Text FX → Flutter Combat`.
