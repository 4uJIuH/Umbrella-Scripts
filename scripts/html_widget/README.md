## Что умеет

Предоставляет интерфейс для загрузки и отображения локальных HTML-виджетов в Umbrella. Сам скрипт не содержит готовых HTML-дизайнов.

- Ищет файлы `.html` в `umbrella\scripts\html_widgets`
- Отображает найденные пользовательские HTML-виджеты в игровом интерфейсе
- Используйте только HTML-файлы, которым доверяете

## Установка

1. Поместите `html_widget.lua` в `umbrella\scripts`.
2. Создайте папку `umbrella\scripts\html_widgets` и добавьте туда доверенные HTML-виджеты.
3. Перезагрузите Lua-скрипты.
4. Откройте `General → Main → HTML Widget`.

# HTML Widget (English)

## What it does

Provides an interface for loading and displaying local HTML widgets in Umbrella. The script does not include ready-made HTML designs.

- Looks for `.html` files in `umbrella\scripts\html_widgets`
- Displays discovered custom HTML widgets in the game interface
- Only use HTML files you trust

## Install

1. Place `html_widget.lua` in `umbrella\scripts`.
2. Create `umbrella\scripts\html_widgets` and add trusted HTML widgets there.
3. Reload the Lua scripts.
4. Open `General → Main → HTML Widget`.
