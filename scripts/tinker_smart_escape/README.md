## Что умеет

Tinker Smart Escape — скрипт для побега на Тинкере. Удерживайте клавишу, и герой будет двигаться к курсору, автоматически используя выбранные предметы и способности. Автор: sataroz. Сделано с помощью Antigravity.

- Движение к курсору с автоматическим применением доступных предметов и способностей
- Поддержка Blink, Wind Waker, Glimmer Cape, Ethereal Blade, Crellas Crozier, Ghost, Eul's, Force Staff и Phase Boots
- Smart Blink во время Wind Waker или перед окончанием невидимости Glimmer Cape
- Постановка турелей позади Тинкера для толчка вперёд
- Защита Ghost, Ethereal Blade или Crellas Crozier с учётом физических и магических угроз
- Визуализация текущего действия, направления побега и радиуса Blink

## Установка

1. Поместите `tinker_smart_escape.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Tinker → Smart Escape`.
4. Включите скрипт, назначьте клавишу побега и выберите предметы.

# Tinker Smart Escape (English)

## What it does

Tinker Smart Escape is an escape script for Tinker. Hold a key and the hero moves towards the cursor while automatically using selected items and abilities. Author: sataroz. Made with Antigravity.

- Moves towards the cursor and automatically uses available items and abilities
- Supports Blink, Wind Waker, Glimmer Cape, Ethereal Blade, Crellas Crozier, Ghost, Eul's, Force Staff, and Phase Boots
- Smart Blink during Wind Waker or just before Glimmer Cape invisibility ends
- Places turrets behind Tinker to push him forward
- Uses Ghost, Ethereal Blade, or Crellas Crozier for protection while accounting for physical and magical threats
- Displays the current action, escape direction, and Blink range

## Install

1. Place `tinker_smart_escape.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Tinker → Smart Escape`.
4. Enable the script, bind the escape key, and select the items you want to use.
