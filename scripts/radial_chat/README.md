## Что умеет

Показывает радиальное меню с настраиваемыми фразами. Удерживайте бинды командного или общего колеса, выберите фразу курсором и отпустите кнопку, чтобы отправить её в соответствующий игровой чат.

- Отдельные колёса для командного и общего чата
- Настраиваемые фразы и бинды
- Выбор сообщения направлением курсора

## Установка

1. Поместите `RadialChat.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → RadialChat → Main`.
4. Выбранная фраза отправляется в соответствующий чат при отпускании бинда.

# RadialChat (English)

## What it does

Displays a radial menu of configurable phrases. Hold the team or all-chat bind, point at a phrase, and release the key to send it to the corresponding in-game chat.

- Separate wheels for team and all chat
- Configurable phrases and keybinds
- Select a message by pointing with the cursor

## Install

1. Place `RadialChat.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Utility → RadialChat → Main`.
4. The selected phrase is sent to the corresponding chat when you release the keybind.
