## Что умеет

Скрипт для управления агром крипов с визуальными индикаторами.

- Переагр по клавише и через подконтрольных существ
- Настраиваемые радиус, партиклы и индикатор перезарядки
- Поддержка контролируемых юнитов и визуалов ограничена радиусом 3000 от героя

## Установка

1. Поместите `creep_aggro.lua` и <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/q-localizer-v1.0.0/_qLocalizer.lua" target="_blank" rel="noopener"><code>!_qLocalizer.lua</code></a> в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты. Меню: Creeps / Крипы → Creep Agro.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Creep Aggro (English)

## What it does

A creep-aggro helper with visual indicators.

- Re-aggro with a key or through controlled units
- Configurable radius, particles, and aggro cooldown indicator
- Controlled-unit actions and visuals are limited to 3000 range from the hero

## Install

1. Place `creep_aggro.lua` and <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/q-localizer-v1.0.0/_qLocalizer.lua" target="_blank" rel="noopener"><code>!_qLocalizer.lua</code></a> in `umbrella\scripts`.
2. Reload the Lua scripts. Menu: Creeps → Creep Agro.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
