# Dazzle Auto Support

автоматически применяет защитные способности и предметы Dazzle / automatically casts Dazzle's defensive spells and items

## Что умеет

Помогает спасать союзников с помощью Shallow Grave, Shadow Wave и защитных предметов. Настраиваются пороги здоровья и условия применения. Автоматическое применение большинства функций включено по умолчанию.

- Автоматический Shallow Grave на критически раненого союзника
- Автоматическое лечение Shadow Wave
- Поддержка Lotus Orb, Glimmer Cape, Eul's, Pipe, Urn/Vessel и Mekansm/Greaves
- Порог здоровья, режим боя и визуализация радиусов

## Установка

1. Поместите `dazzle_support_rus.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Dazzle → Dazzle Support RUS`.
4. Проверьте переключатели автоматического применения перед игрой.

# Dazzle Auto Support (English)

## What it does

Helps save allies using Shallow Grave, Shadow Wave, and defensive items. Configure health thresholds and casting conditions. Most automatic features are enabled by default.

- Automatically casts Shallow Grave on a critically injured ally
- Automatic Shadow Wave healing
- Supports Lotus Orb, Glimmer Cape, Eul's, Pipe, Urn/Vessel, and Mekansm/Greaves
- Health thresholds, combat conditions, and range visuals

## Install

1. Place `dazzle_support_rus.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Dazzle → Dazzle Support RUS`.
4. Review the automatic-cast toggles before playing.
