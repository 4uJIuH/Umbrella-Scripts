## Что умеет

Отслеживает вражеские телепорты и пытается попасть Sun Strike, только если урон должен быть летальным.

- Реагирует на начало телепортации врага
- Применяет Sun Strike только при ожидаемом летальном уроне
- Включается и отключается в настройках Invoker

## Установка

1. Поместите `invokersunstikevtp.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Invoker → Auto Usage → Sun Strike Settings`.

# Invoker Sun Strike on TP (English)

## What it does

Tracks enemy teleports and attempts to land Sun Strike only when its damage is expected to be lethal.

- Reacts when an enemy starts teleporting
- Casts Sun Strike only when the expected damage is lethal
- Can be enabled or disabled in Invoker settings

## Install

1. Place `invokersunstikevtp.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Invoker → Auto Usage → Sun Strike Settings`.
