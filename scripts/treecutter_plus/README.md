## Что умеет

Экспериментальный биндуемый скрипт: ищет деревья на пути и помогает срубить их вместо обхода. Автор отмечает, что текущая версия сделана с минимальным набором функций.

- Ищет подходящие деревья вдоль пути к курсору
- Поддерживает Quelling Blade и Battle Fury
- Можно настроить ширину коридора и дистанцию поиска

## Установка

1. Поместите `opti.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → TreeCutter+`; для активации можно назначить бинды в настройках.

# TreeCutter+ (English)

## What it does

An experimental, bindable script that looks for trees along the route and helps cut through them instead of walking around. The author describes this version as a minimal prototype.

- Looks for suitable trees along the route to the cursor
- Supports Quelling Blade and Battle Fury
- Configurable corridor width and search distance

## Install

1. Place `opti.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Utility → TreeCutter+`; you can assign a keybind in the settings.
