## Что умеет

Небольшой Kez-скрипт для приёма с Kazurai Katana: нажмите предмет по врагу, пока переключение стойки доступно.

- Помогает выполнить серию диспелов с Kazurai Katana
- Требует, чтобы смена стойки не находилась на перезарядке
- Поставляется с локализацией меню

## Установка

1. Поместите `kez_raptor_dispel.lua` в `umbrella\scripts`.
2. Перезагрузите скрипты и откройте настройки Kez.

# Kez Raptor Dance Dispel (English)

## What it does

A small Kez helper for a Kazurai Katana interaction: use the item on an enemy while stance switching is available.

- Helps perform repeated dispels with Kazurai Katana
- Requires stance switching to be off cooldown
- Includes its own menu localization

## Install

1. Place `kez_raptor_dispel.lua` in `umbrella\scripts`.
2. Reload scripts and open the Kez settings.
