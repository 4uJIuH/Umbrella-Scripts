## Что умеет

Автоматически управляет существующим Healing Ward: удерживает его рядом с союзниками для лечения и отводит от врагов и опасных крипов, пытающихся уничтожить вард.

- Автоматически выбирает союзников для лечения по порогу здоровья
- Сохраняет дистанцию до угроз и отступает от врагов и крипов
- Использует поиск проходимого маршрута и учитывает ручные приказы
- Настройки доступны в `Ward Control`

## Установка

1. Поместите `JuggernautWardControl.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Juggernaut → Main Settings → Ward Control`.

# Juggernaut Ward Control (English)

## What it does

Automatically controls an existing Healing Ward: keeps it near allies to heal and moves it away from enemies and threatening creeps that may destroy it.

- Automatically selects allies to heal based on a health threshold
- Keeps distance from threats and retreats from enemies and creeps
- Uses walkable-path checks and respects manual orders
- Settings are available under `Ward Control`

## Install

1. Place `JuggernautWardControl.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Juggernaut → Main Settings → Ward Control`.
