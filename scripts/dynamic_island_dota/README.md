## Что умеет

Dynamic Island для Dota 2 показывает важные игровые данные, уведомления и активности в компактном настраиваемом интерфейсе. Автор: "ur2m" (GitHub: @qhols). Скрипт распространяется из репозитория автора.

- Показывает статистику матча, игровые события, уведомления и таймеры
- Поддерживает музыкальный плеер, обложки и синхронизированные тексты песен через дополнительный media bridge
- Настраивает внешний вид островка, виджеты, уведомления и сочетания клавиш
- Сам Lua-скрипт работает без media bridge; музыка и звуки требуют запущенный `media_bridge.exe`

## Установка

1. Скачайте <a href="https://github.com/qhols/DynamicIsland-Dota/releases/download/v2.5.3/dynamic_island.lua" target="_blank" rel="noopener"><code>dynamic_island.lua</code></a> и поместите файл в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и включите скрипт в `General → Dynamic Island`.
3. Островок работает и без дополнительной программы. Для музыки и звуков скачайте <a href="https://github.com/qhols/DynamicIsland-Dota/releases/download/v2.5.3/media_bridge.exe" target="_blank" rel="noopener"><code>media_bridge.exe</code></a> из релиза автора и запустите его вместе с Dota 2.
4. Инструкция по автоматическому запуску bridge: <a href="https://github.com/qhols/DynamicIsland-Dota/blob/main/docs/autostart.md" target="_blank" rel="noopener">документация автора</a>.

# Dynamic Island (English)

## What it does

Dynamic Island for Dota 2 displays useful game information, notifications, and activities in a compact, customizable interface. Author: "ur2m" (GitHub: @qhols). The script is distributed from its author's repository.

- Shows match stats, game events, notifications, and timers
- Supports a music player, album art, and synced lyrics through the optional media bridge
- Customizes the island, widgets, notifications, and keybinds
- The Lua script works without the media bridge; music and sounds require `media_bridge.exe` to be running

## Install

1. Download <a href="https://github.com/qhols/DynamicIsland-Dota/releases/download/v2.5.3/dynamic_island.lua" target="_blank" rel="noopener"><code>dynamic_island.lua</code></a> and place it in `umbrella\scripts`.
2. Reload the Lua scripts and enable it under `General → Dynamic Island`.
3. The island also works without the companion app. For music and sounds, download <a href="https://github.com/qhols/DynamicIsland-Dota/releases/download/v2.5.3/media_bridge.exe" target="_blank" rel="noopener"><code>media_bridge.exe</code></a> from the author's release and run it with Dota 2.
4. See the author's <a href="https://github.com/qhols/DynamicIsland-Dota/blob/main/docs/autostart.md" target="_blank" rel="noopener">bridge auto-start guide</a>.
