## Что умеет

Подбирает тайминги предметов и способностей для разгона Spirit Breaker, сохраняя нужные баффы к столкновению.

- может применить Swift Blink перед Charge
- использует ускорения во время разгона и защитные предметы перед ударом
- показывает примерное время до столкновения

## Установка

1. Поместите `spirit_breaker_charge.lua` и `!_qLocalizer.lua` в `Umbrella\scripts`.
2. Перезагрузите скрипты и откройте Spirit Breaker → Charge Combo.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Spirit Breaker Charge Combo (English)

## What it does

Times Spirit Breaker's items and abilities during the charge, preserving selected buffs for the collision.

- can use Swift Blink before Charge
- uses speed boosts during the charge and defensive items before impact
- shows an estimated time until collision

## Install

1. Place `spirit_breaker_charge.lua` and `!_qLocalizer.lua` in `Umbrella\scripts`.
2. Reload scripts and open Spirit Breaker → Charge Combo.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
