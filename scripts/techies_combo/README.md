## Что умеет

Улучшенное комбо Techies с возможностью блинкнуть из боя после завершения последовательности.

- агрессивный режим быстрее использует Hex, сокращая окно для доджа
- режим максимального урона старается применить больше способностей и предметов
- опциональный выход Blink после комбо

## Установка

1. Поместите `techies_combo.lua` и `!_qLocalizer.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Techies Combo (English)

## What it does

An improved Techies combo with an optional Blink escape after the sequence finishes.

- aggressive mode uses Hex sooner, reducing the dodge window
- maximum-damage mode tries to use more abilities and items
- optional Blink-out after the combo

## Install

1. Place `techies_combo.lua` and `!_qLocalizer.lua` in `Umbrella\scripts`.
2. Reload Lua scripts.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
