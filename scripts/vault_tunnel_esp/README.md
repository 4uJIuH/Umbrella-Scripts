## Что умеет

ESP для отслеживания разрушаемых объектов Souls Vault и Rem's Tunnel в Deadlock.

- Отображает 3D-бокс или кольцо, имя объекта и расстояние до него
- После разрушения Souls Vault показывает таймер возрождения на объекте и миникарте

## Установка

1. Поместите <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/vault-tunnel-esp-v1.0.0/VaultTunnelESP.lua" target="_blank" rel="noopener"><code>VaultTunnelESP.lua</code></a> в папку скриптов Deadlock.
2. Перезагрузите Lua-скрипты.
3. Откройте настройки: `Visuals → World → Show Me More → Vault & Tunnel ESP`.

# Souls Vault / Rem's Tunnel ESP (English)

## What it does

An ESP for tracking breakable Souls Vault and Rem's Tunnel objects in Deadlock.

- Draws a 3D box or ring, object name, and distance
- After a Souls Vault is destroyed, shows its respawn countdown on the object and minimap

## Install

1. Place <a href="https://github.com/4uJIuH/umbrella-scripts/releases/download/vault-tunnel-esp-v1.0.0/VaultTunnelESP.lua" target="_blank" rel="noopener"><code>VaultTunnelESP.lua</code></a> in your Deadlock scripts folder.
2. Reload the Lua scripts.
3. Open settings: `Visuals → World → Show Me More → Vault & Tunnel ESP`.

## Changelog

**Version 1.0.0**

- Added 3D box and ring markers for Souls Vault and Rem's Tunnel.
- Added object names and distance labels.
- Added a respawn countdown for destroyed Souls Vault objects, shown on the object and minimap.
- The script is standalone and does not require `!_qLocalizer.lua`.
