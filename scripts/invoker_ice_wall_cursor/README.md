## Что умеет

Показывает предполагаемое положение стены при удержании бинда и применяет Ice Wall в сторону курсора. Скрипт сам не создаёт способность.

- Показывает положение Ice Wall при удержании бинда
- Применяет стену в сторону курсора
- Для автосоздания способности назначьте Ice Wall на тот же бинд в настройках Инвокера

## Установка

1. Поместите `ice_wall_on_cursor.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Настройте `Heroes → Hero List → Invoker → Main Settings → Cast On Cursor`; при необходимости назначьте Ice Wall на тот же бинд.

# Invoker Ice Wall on Cursor (English)

## What it does

Previews the wall placement while the bind is held and casts Ice Wall toward the cursor. The script does not create the ability itself.

- Previews Ice Wall placement while holding the bind
- Casts the wall toward the cursor
- To create the ability automatically, bind Ice Wall to the same key in Invoker settings

## Install

1. Place `ice_wall_on_cursor.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Configure `Heroes → Hero List → Invoker → Main Settings → Cast On Cursor`; bind Ice Wall to the same key if needed.
