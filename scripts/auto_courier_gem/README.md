## Что умеет

Автоматически отправляет курьера подобрать выпавший Gem of True Sight, а после подбора возвращает его в тайник. Создавался для Turbo.

- Обнаруживает выпавший Gem и отправляет курьера к предмету
- Возвращает Gem в тайник после подбора
- Настройки находятся в `Scripts → Utilities → Courier Gem`

## Установка

1. Поместите `auto_courier_gem.lua` в `umbrella\scripts`.
2. Перезагрузите скрипты и откройте `Scripts → Utilities → Courier Gem`.

# Auto Courier Gem (English)

## What it does

Automatically sends the courier to pick up a dropped Gem of True Sight, then returns it to stash. Created for Turbo.

- Detects a dropped Gem and sends the courier to it
- Returns the Gem to stash after pickup
- Settings are under `Scripts → Utilities → Courier Gem`

## Install

1. Place `auto_courier_gem.lua` in `umbrella\scripts`.
2. Reload scripts and open `Scripts → Utilities → Courier Gem`.
