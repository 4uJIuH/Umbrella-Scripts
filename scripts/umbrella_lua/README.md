## Что умеет

Пакет с рекомендациями и справочными материалами для разработки Lua-скриптов Umbrella. Это инструмент для разработки, а не скрипт, загружаемый в игру.

- Содержит справочные материалы для разработки Lua-скриптов Umbrella
- Не устанавливается в папку <code>umbrella\scripts</code> и не загружается игрой

## Установка

1. Скачайте архив из <a href="https://github.com/But3rflys/umbrella-work/releases/download/umbrella-lua-v1.0.4/umbrella-lua.zip" target="_blank" rel="noopener">последнего релиза автора</a>.
2. Установите его в совместимый инструмент разработки согласно его инструкции.

# Umbrella Lua Developer Skill (English)

## What it does

A package of guidance and reference material for developing Umbrella Lua scripts. This is a development tool, not a script loaded by the game.

- Provides reference material for developing Umbrella Lua scripts
- It is not installed in <code>umbrella\scripts</code> and is not loaded by the game

## Install

1. Download the archive from the author’s <a href="https://github.com/But3rflys/umbrella-work/releases/download/umbrella-lua-v1.0.4/umbrella-lua.zip" target="_blank" rel="noopener">latest release</a>.
2. Install it in a compatible development tool using that tool’s instructions.
