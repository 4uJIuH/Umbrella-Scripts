автоматически лечит союзников способностью Mist Coil / automatically heals allies with Mist Coil

## Что умеет

Выбирает союзную цель и автоматически применяет Mist Coil для лечения с настраиваемыми порогами здоровья и параметрами приоритета.

- Автоматическое лечение союзников
- Настраиваемые пороги начала и прекращения лечения
- Панель состояния и параметры отображения

## Установка

1. Поместите `AutoMistCoil.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Abaddon → Auto Usage → AutoMistCoil`.

# Abaddon AutoMistCoil (English)

## What it does

Selects an allied target and automatically casts Mist Coil to heal, with configurable health thresholds and target-priority settings.

- Automatic ally healing
- Configurable healing start and stop thresholds
- Status panel and display options

## Install

1. Place `AutoMistCoil.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Abaddon → Auto Usage → AutoMistCoil`.
