## Что умеет

Показывает врагов, которые могут добраться до героя, и примерное время их прибытия. Для работы нужны файлы `ulib`.

- Предупреждает о телепортации к герою, в том числе из тумана войны
- Показывает ближайших и скрытых врагов с оценкой маршрута и времени
- Кнопка установки в Script Manager скачивает скрипт и все необходимые файлы `ulib`

## Установка

1. Нажмите «Установить» у Gank Threat в Script Manager, чтобы скачать скрипт и все файлы `ulib`.
2. Скопируйте папку `ulib` из <a href="https://github.com/4uJIuH/umbrella-scripts/tree/main/scripts/gank_threat/ulib" target="_blank" rel="noopener">исходников</a> в `umbrella\scripts\ulib`.
3. Перезагрузите Lua-скрипты. Настройки: General → Gank Threat.

# Gank Threat (English)

## What it does

Shows enemies who may reach the hero and estimates how long they could take. The `ulib` files are required.

- Warns about incoming teleports, including those hidden by fog of war
- Tracks nearby and unseen enemies with route and arrival estimates
- The Script Manager Install button downloads the script and all required `ulib` files

## Install

1. Click Install for Gank Threat in Script Manager to download the script and all `ulib` files.
2. Copy the `ulib` folder from the <a href="https://github.com/4uJIuH/umbrella-scripts/tree/main/scripts/gank_threat/ulib" target="_blank" rel="noopener">source files</a> into `umbrella\scripts\ulib`.
3. Reload the Lua scripts. Settings: General → Gank Threat.
