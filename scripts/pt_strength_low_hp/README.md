# Power Treads Strength on Low HP

переключает Power Treads на силу при низком здоровье / switches Power Treads to Strength at low health

## Что умеет

Переключает Power Treads на силу, когда здоровье опускается ниже заданного порога. Может также реагировать на атаки врагов, а затем возвращать выбранный основной атрибут.

- Настраиваемый порог здоровья
- Дополнительное переключение на силу при атаках врага
- Возвращает Power Treads на выбранный основной атрибут
- Автор рекомендует вручную выбрать основной атрибут: его автоопределение пока не доработано

## Установка

1. Поместите `pt_abs.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Настройте `Scripts → Combat → PTabs` и вручную выберите основной атрибут.

# Power Treads Strength on Low HP (English)

## What it does

Switches Power Treads to Strength below a configured health threshold. It can also react to enemy attacks and then restore the selected primary attribute.

- Configurable health threshold
- Optional switch to Strength when attacked by enemies
- Restores Power Treads to the selected primary attribute
- The author recommends choosing the primary attribute manually because auto-detection is unfinished

## Install

1. Place `pt_abs.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Configure `Scripts → Combat → PTabs` and select the primary attribute manually.
