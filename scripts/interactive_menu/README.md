## Что умеет

Визуальная тема для меню с частицами, соединениями, следом курсора и плавными эффектами открытия. Настраиваются палитра, цветовые переливы, плотность частиц и оформление.

- Анимированный фон с частицами и соединениями
- Эффекты курсора и плавные переходы меню
- Настраиваемые цвета, яркость, скорость и плотность эффектов
- Русский и английский интерфейс

## Установка

1. Поместите `InteractiveMenu.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → InteractiveMenu RU` и настройте фон и эффекты.

# InteractiveMenu (English)

## What it does

A visual menu theme with particles, connecting lines, cursor trails, and smooth opening effects. Customize the palette, color transitions, particle density, and appearance.

- Animated background with particles and connections
- Cursor effects and smooth menu transitions
- Configurable colors, brightness, speed, and effect density
- Russian and English interface

## Install

1. Place `InteractiveMenu.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Main → InteractiveMenu RU` to configure the background and effects.
