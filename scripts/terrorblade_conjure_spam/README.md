## Что умеет

Помогает использовать Conjure Image вместе со встроенным фармом иллюзиями, чтобы не упускать дополнительный фарм во время игры.

- Автоматизирует использование иллюзий Terrorblade в поддерживаемом режиме
- Предназначен для совместной работы со встроенной функцией фарма иллюзиями

## Установка

1. Поместите `TerrorbladeConjureSpam.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Настройте `General → Terrorblade → Conjure Image → Settings → Conjure Spam`.

# Terrorblade Conjure Spam (English)

## What it does

Helps use Conjure Image alongside built-in illusion farming so additional farm is not missed during play.

- Automates Terrorblade illusion use in the supported mode
- Designed to work with the built-in illusion-farming feature

## Install

1. Place `TerrorbladeConjureSpam.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Configure `General → Terrorblade → Conjure Image → Settings → Conjure Spam`.
