## Что умеет

Отображает над видимыми вражескими героями их скорость и разницу относительно вашего героя. Цвет помогает быстро оценить, кто быстрее или движется с сопоставимой скоростью.

- Сравнение скорости вашего героя со скоростью врагов
- Цветовая индикация быстрее / медленнее / примерно одинаковая скорость
- Настраиваемые размер, смещение, цвета и яркость

## Установка

1. Поместите `speed.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Info Screen → Main → Heroes Overlay → Main → Speed Check`.

# Hero Speed Overlay (English)

## What it does

Displays visible enemy heroes' movement speed and the difference relative to your hero. Color coding helps show who is faster or moving at a similar speed.

- Compare your hero's movement speed with enemies
- Color-coded faster / slower / similar speed
- Configurable size, offset, colors, and glow

## Install

1. Place `speed.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Info Screen → Main → Heroes Overlay → Main → Speed Check`.
