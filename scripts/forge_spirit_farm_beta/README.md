## Что умеет

Бета-версия управления Forge Spirits с фармом линий и попытками стакать кемпы. Автор предупреждает, что многие функции ещё требуют проверки и работают нестабильно.

- Назначение ролей «Стакер» и «Авто» для духов
- Выбор кемпов на карте и настраиваемое время отхода
- Фарм линий и попытки ломать руны
- Предварительная бета: возможны ошибки, сборки и поведение юнитов не проверены

## Установка

1. Поместите `forge_spirit_farm.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Тестируйте только если готовы к ошибкам; автор помечает эту сборку как нестабильную.

# Forge Spirit Farm (Beta) (English)

## What it does

A beta controller for Forge Spirits that farms lanes and attempts camp stacks. The author warns that several features are untested and unstable.

- Assign Stacker and Auto roles to spirits
- Select camps on the map and configure the retreat time
- Lane farming and attempted rune breaking
- Early beta: errors are possible and unit behavior has not been validated

## Install

1. Place `forge_spirit_farm.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Test only if you accept possible bugs; the author labels this build unstable.
