## Что умеет

Перезалив скрипта Keeper of the Light с Auto Chakra и дополнительными функциями. Тема исходной публикации удалена.

- автоматически применяет Chakra Magic при подходящей цели поблизости
- содержит дополнительные функции для Keeper of the Light

## Установка

1. Поместите `kotl_auto_chakra.lua` в `Umbrella\scripts`.
2. Перезагрузите скрипты и откройте меню Keeper of the Light.
