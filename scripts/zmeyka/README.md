## Что умеет

Внутриигровая версия классической «Змейки» с выбором скорости, размера поля и режима еды, а также настройками стен и языка.

- Старт, пауза и перезапуск игры из меню
- Настраиваемые скорость и размер игрового поля
- Выбор режима еды и поведения стен
- Интерфейс на русском и английском языках

## Установка

1. Поместите `zmeyka.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Змейка → Змейка`.

# Змейка (English)

## What it does

An in-game version of the classic Snake game with configurable speed, board size, food mode, wall behavior, and language.

- Start and restart the game from its menu
- Configurable game speed and board size
- Food and wall behavior options
- Russian and English interface

## Install

1. Place `zmeyka.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Snake Game → Snake Game`.
