## Что умеет

Ищет текст в интерфейсе и позволяет заменить выбранное совпадение, все совпадения или весь текст. Скрипт изначально создавался для компендиума.

- Поиск надписей по тексту
- Замена выбранного совпадения или всех результатов
- Сброс изменений к исходному тексту

## Установка

1. Поместите `txtspoofer.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Visuals → TXT Spoofer`.

# TXT Spoofer (English)

## What it does

Searches interface text and lets you replace a selected match, all matches, or all text. The script was originally made for the Compendium.

- Searches for labels by text
- Replaces a selected match or every result
- Restores modified text to its original value

## Install

1. Place `txtspoofer.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Visuals → TXT Spoofer`.
