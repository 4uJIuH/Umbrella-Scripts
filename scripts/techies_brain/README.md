## Что умеет

Единый контроллер комбо: Hex, Sticky Bomb, Tazer, Ethereal Blade, Blast Off, мины и детонация. Автор рекомендует не запускать одновременно другой скрипт комбо Techies.

- выполняет последовательность способностей и предметов
- настраивается через меню `Heroes → Hero List → Techies → Brain`

## Установка

1. Поместите `techies_brain.lua` в `Umbrella\scripts` и перезагрузите скрипты.
2. Отключите или отвяжите другой скрипт комбо Techies и задайте Combo Key в `Heroes → Hero List → Techies → Brain`.

# Techies Brain Combo (English)

## What it does

A unified combo controller for Hex, Sticky Bomb, Tazer, Ethereal Blade, Blast Off, mines, and detonation. The author recommends not running another Techies combo script at the same time.

- executes a sequence of abilities and items
- configured under `Heroes → Hero List → Techies → Brain`

## Install

1. Place `techies_brain.lua` in `Umbrella\scripts` and reload scripts.
2. Disable or unbind any other Techies combo script and set the Combo Key under `Heroes → Hero List → Techies → Brain`.
