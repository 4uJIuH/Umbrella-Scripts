## Что умеет

Добавляет интерфейс для просмотра TikTok в Umbrella. По описанию автора для доступа может понадобиться сторонний обходчик.

- Открывает вкладку TikTok в разделе скриптов
- Поставляется и обновляется автором в отдельном GitHub-репозитории
- Доступность зависит от внешних сетевых ограничений и сервисов

## Установка

1. Скачайте `tiktok.lua` из <a href="https://github.com/gdhost4-eng/umbrella-tiktok/releases" target="_blank" rel="noopener">официальных релизов автора</a> или используйте менеджер.
2. Поместите файл в `umbrella\scripts` и перезагрузите Lua-скрипты.
3. Сторонние сетевые обходчики не входят в поставку этого репозитория.

# TikTok (English)

## What it does

Adds a TikTok viewing interface to Umbrella. The author notes that a third-party network workaround may be needed for access.

- Adds a TikTok tab to the scripts section
- Maintained and updated by the author in a separate GitHub repository
- Availability depends on external network restrictions and services

## Install

1. Download `tiktok.lua` from the author's <a href="https://github.com/gdhost4-eng/umbrella-tiktok/releases" target="_blank" rel="noopener">official releases</a> or use the manager.
2. Place the file in `umbrella\scripts` and reload Lua scripts.
3. Third-party network workarounds are not included in this repository.
