## Что умеет

Информационный watermark в стиле Neverlose с настраиваемыми показателями. Настройки сохраняются в `neverlose_metrics.ini`.

- Показывает выбранные системные и игровые показатели, включая ping, FPS и время
- Позволяет включать и выключать отдельные элементы
- Сохраняет настройки в INI-файл

## Установка

1. Поместите `Neverlose.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Sense Metrics → Sense`.

# Sense Metrics (English)

## What it does

A Neverlose-style information watermark with configurable metrics. Settings are stored in `neverlose_metrics.ini`.

- Displays selected system and game metrics, including ping, FPS, and time
- Toggle individual elements
- Saves settings to an INI file

## Install

1. Place `Neverlose.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `General → Sense Metrics → Sense`.
