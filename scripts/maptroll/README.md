## Что умеет

Утилита для отображения текста на миникарте с настраиваемым положением, размером и интервалом.

- Ручной режим и автоматическая отрисовка рядом с выбранными союзниками
- Настройки размера, координат, задержки и длины сообщения

## Установка

1. Поместите `maptroll.lua` в `umbrella\scripts` и перезагрузите Lua-скрипты.
2. Откройте Scripts → Other → Map Chat Troll.

# Map Chat Troll (English)

## What it does

A utility for displaying text on the minimap with configurable position, size, and interval.

- Manual mode and automatic drawing near selected allies
- Adjustable size, coordinates, delay, and message length

## Install

1. Place `maptroll.lua` in `umbrella\scripts` and reload the Lua scripts.
2. Open Scripts → Other → Map Chat Troll.
