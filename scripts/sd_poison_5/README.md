## Что умеет

Вспомогательный модуль только для Shadow Poison Release: не заменяет основной комбо-скрипт Shadow Demon.

- Подрывает ваши стаки на 5 и более, учитывая 25-й талант
- Проверяет талант, владельца стаков и исключает иллюзии
- Можно ограничить работу удержанием клавиши комбо
- Не перебивает другой каст или канал; доступен debug log

## Установка

1. Поместите `sd_poison_5.lua` в `%cheat_dir%\scripts`.
2. Перезагрузите скрипты. Настройки: General → Main → SD Poison 5 → Main → Settings.
3. Помните: Release взрывает все ваши стаки на всех целях одновременно.

# Shadow Demon Poison 5 (English)

## What it does

A companion module for Shadow Poison Release only; it does not replace a Shadow Demon combo script.

- Releases your stacks at 5 or more, accounting for the level 25 talent
- Checks the talent, stack ownership, and excludes illusions
- Can be limited to while a combo key is held
- Does not interrupt another cast or channel; includes a debug log option

## Install

1. Place `sd_poison_5.lua` in `%cheat_dir%\scripts`.
2. Reload scripts. Settings: General → Main → SD Poison 5 → Main → Settings.
3. Note: Release detonates all your stacks on all targets at once.
