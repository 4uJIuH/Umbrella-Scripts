# PogodaUI

показывает погоду и прогноз для выбранного города / shows current weather and forecast for a selected city

## Что умеет

Погодный виджет на основе Open-Meteo с автоопределением города, прогнозом и настройками оформления. Включает дату и время, сведения о погоде и дополнительные оповещения.

- Автоопределение города и периодическое обновление погоды
- Почасовой прогноз, восход, закат, давление и UV-индекс
- Настройки шрифта, темы, размера, прозрачности и положения
- Виджет оповещений и настройки отладки

## Установка

1. Поместите `PogodaUI.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → PogodaUI`.

# PogodaUI (English)

## What it does

An Open-Meteo weather widget with city detection, forecasts, and appearance settings. Includes date and time, weather details, and additional alerts.

- Automatically detects the city and refreshes weather data
- Hourly forecast, sunrise, sunset, pressure, and UV index
- Font, theme, size, opacity, and position settings
- Alert widget and debug options

## Install

1. Place `PogodaUI.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Main → PogodaUI`.
