# Cooldown Ping

сообщает команде о кулдаунах способностей и предметов / notifies the team about ability and item cooldowns

<!-- releases:end -->

## Что умеет

Отправляет командное уведомление с оставшимся временем перезарядки, когда данные о кулдауне доступны. Можно отдельно включить уведомления о способностях и предметах врагов.

- Уведомления о кулдаунах способностей и предметов
- Показывает имя способности и владельца
- Автоматически выбирает русский или английский интерфейс

## Установка

1. Поместите `CooldownPing.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Cooldown Ping → Cooldown Ping`.

# Cooldown Ping (English)

## What it does

Sends a team notification with the remaining cooldown when that information is available. Notifications for enemy abilities and items can be enabled separately.

- Cooldown notifications for abilities and items
- Displays the ability name and its owner
- Automatically selects a Russian or English interface

## Install

1. Place `CooldownPing.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Cooldown Ping → Cooldown Ping`.
