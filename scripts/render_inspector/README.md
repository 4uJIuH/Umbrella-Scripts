веб-инструмент для исследования отрисованных элементов / a web tool for inspecting rendered screen elements

## Что умеет

Инструмент для скриптеров Umbrella: помогает исследовать содержимое экрана, в том числе элементы Render Target и Arc Panel. Исходники и веб-версия доступны в репозитории автора.

- просмотр элементов, которые рендерятся на экране
- помогает разбирать Render Target
- можно исследовать панели, включая Arc Panel

## Установка

1. Нажмите «Скачать», чтобы открыть веб-инструмент.
2. Исходный код проекта доступен по ссылке GitHub.

# Render Inspector (English)

## What it does

A tool for Umbrella scripters to inspect what is rendered on screen, including Render Target elements and Arc Panel. The author's repository contains the source and web version.

- inspect elements rendered on screen
- helps investigate Render Target output
- explore panels such as Arc Panel

## Install

1. Click Download to open the web tool.
2. The project source is available from the GitHub link.
