## Что умеет

Помогает блокировать линию подконтрольными существами: при удержании бинда показывает точки для блока и управляет юнитами. Скрипт экспериментальный, поэтому часть крипов может проходить.

- Поддерживает подконтрольных существ, иллюзии и клонов
- Показывает и запоминает точки для блока
- Для блока героем автор рекомендует использовать штатный скрипт Umbrella

## Установка

1. Поместите `creep_block.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Creeps → Main → Creep Block`.

# Creep Block (English)

## What it does

Helps block the lane with controllable units: hold the keybind to show blocking spots and direct units. This is an experimental script, so some creeps may get through.

- Supports controllable units, illusions, and clones
- Displays and saves blocking spots
- For blocking with your hero, the author recommends Umbrella's built-in script

## Install

1. Place `creep_block.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Creeps → Main → Creep Block`.
