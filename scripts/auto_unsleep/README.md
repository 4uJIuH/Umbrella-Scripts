# AutoUnsleep

будит героев из Nightmare с помощью подконтрольных юнитов / wakes heroes from Nightmare using controllable units

## Что умеет

Автоматически приказывает подконтрольным юнитам атаковать уснувшую цель, чтобы прервать Nightmare. Можно настроить помощь себе и союзникам; врагов скрипт будит только при спасении от Nightmare вражеского Bane.

- Пробуждает себя и союзников от Nightmare
- Атакует уснувшую цель подходящим подконтрольным юнитом
- Опционально спасает врагов от Nightmare, наложенного Bane противника
- Настраиваемый радиус поиска

## Установка

1. Поместите `AutoUnsleep.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Settings → General → Units Controller → AutoUnsleep`.

# AutoUnsleep (English)

## What it does

Automatically orders a controllable unit to attack a sleeping target and interrupt Nightmare. Configure help for yourself and allies; enemies are only awakened when saving them from an opposing Bane's Nightmare.

- Wakes yourself and allies from Nightmare
- Uses a suitable controllable unit to attack the sleeping target
- Optional rescue of enemies from an opposing Bane's Nightmare
- Configurable search radius

## Install

1. Place `AutoUnsleep.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Settings → General → Units Controller → AutoUnsleep`.
