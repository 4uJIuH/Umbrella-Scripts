## Что умеет

Сопоставляет требуемые жетоны с героями, которые могут их дать, и показывает рекомендации во время выбора героя. Можно включить подсказки и настроить глубину планирования.

- Рекомендации героев для нужных жетонов
- Настраиваемая глубина планирования по ветке
- Обновление и отображение подсказок в фазе выбора

## Установка

1. Поместите `dark.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → Dark Carnival → Main → Настройки`.

# Dark Carnival Suggest Heroes (English)

## What it does

Matches required tokens to heroes that can grant them and displays recommendations during hero selection. Enable suggestions and configure how far ahead to plan along the branch.

- Hero recommendations for needed tokens
- Configurable planning depth along the branch
- Refreshable suggestions during hero selection

## Install

1. Place `dark.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Main → Dark Carnival → Main → Настройки`.
