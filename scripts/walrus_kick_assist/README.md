## Что умеет

По бинду помогает выбрать цель и направление удара Tusk. Поддерживает выбор по союзнику, скоплению союзников или курсору, автоматический Snowball, Blink и сбивание Linken's Sphere; содержит HUD и проверки Lotus.

- Режимы выбора цели: ближайший союзник, группа союзников, курсор или выбранная цель
- Комбо с Blink и Snowball с настройкой задержки
- Настраиваемые предметы для попытки сбить Linken's Sphere
- Проверка Lotus и интерактивный перемещаемый HUD

## Установка

1. Поместите `walrus_kick_assist.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Tusk → Walrus Kick Assist` или `General → Tusk → Walrus Kick Assist`.

# Walrus Kick Assist (English)

## What it does

On a keybind, helps select a target and kick direction for Tusk. Supports ally, ally-cluster, and cursor targeting, automatic Snowball, Blink, and Linken's Sphere breakers, with Lotus checks and an interactive HUD.

- Target modes: nearest ally, ally cluster, cursor, or selected target
- Blink and Snowball combo with configurable delay
- Configurable items for attempting to break Linken's Sphere
- Lotus checks and an interactive, movable HUD

## Install

1. Place `walrus_kick_assist.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Tusk → Walrus Kick Assist` or `General → Tusk → Walrus Kick Assist`.
