## Что умеет

Запускает последовательность действий с предметом на земле и Tempest Double. В описании автора отмечены возможные ошибки; не рекомендуется для рейтинговых игр.

- Запуск сценария по бинду на выбранную цель
- Управляет оригиналом Arc Warden и Tempest Double по заданным фазам
- Показывает состояние, предмет и счётчики в оверлее
- Включает аварийную команду для подбора предмета

## Установка

1. Поместите `arc_warden_heist.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Включайте сценарий только после ознакомления с настройками и предупреждением автора.

# Arc Warden's Heist (English)

## What it does

Runs a sequence involving an item on the ground and Tempest Double. The author warns that bugs may occur and advises against ranked games.

- Start the sequence with a bind on the selected target
- Controls Arc Warden and Tempest Double through its phases
- Displays phase, item, and counters in an overlay
- Includes an emergency item-pickup command

## Install

1. Place `arc_warden_heist.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Read the settings and the author's warning before enabling the sequence.
