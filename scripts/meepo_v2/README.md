## Что умеет

Бета-скрипт для Meepo с настройками комбинаций, утилит, предметов, автоматического спасения и AutoFarm. Автор продолжает разработку — возможны изменения и ошибки.

- Настройки комбо и управления клонами
- Утилиты, управление предметами и автоматическое спасение
- Параметры AutoFarm и отображения
- Бета-версия: функции и стабильность могут меняться

## Установка

1. Поместите `meepo_v2.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Meepo → Meepo Panel`.

# Meepo V2 (English)

## What it does

A Meepo beta script with combo, utility, item, auto-save, and AutoFarm settings. The author is still developing it, so features and behavior may change.

- Combo and clone-control settings
- Utilities, item control, and automated saves
- AutoFarm and display options
- Beta release: features and stability may change

## Install

1. Place `meepo_v2.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Meepo → Meepo Panel`.
