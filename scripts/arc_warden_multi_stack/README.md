## Что умеет

Пытается одновременно стаковать несколько кемпов с помощью основного героя и клона.

- Автор сообщает о стабильной работе на стороне сил Света
- Для запуска нужно нажать клавишу старта три раза
- На стороне сил Тьмы поведение не работает надёжно

## Установка

1. Поместите `arc_warden_multi_stack.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и изучите бинды перед использованием.

# Arc Warden Multi Stack (English)

## What it does

Attempts to stack several camps using the main hero and the clone.

- The author reports reliable behavior on the Radiant side
- Press the start key three times to begin
- Dire-side behavior is reported as unreliable

## Install

1. Place `arc_warden_multi_stack.lua` in `umbrella\scripts`.
2. Reload the Lua scripts and review the binds before use.
