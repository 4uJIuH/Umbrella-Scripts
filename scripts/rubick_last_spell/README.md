## Что умеет

Текстовый индикатор последнего использованного заклинания. Помогает, когда стандартное отображение способности пропадает, если враг выходит из поля зрения.

- Показывает последнее использованное заклинание текстом
- Настраиваются время отображения и внешний вид индикатора
- Можно включить отображение использованных предметов

## Установка

1. Поместите `rubick_spells.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Rubick → Last Spell ESP`.

# Rubick Last Spell (English)

## What it does

A text indicator for the most recently used spell. It remains useful when the built-in ability drawing disappears after an enemy leaves vision.

- Displays the last used spell as text
- Configurable display duration and indicator appearance
- Optionally displays used items

## Install

1. Place `rubick_spells.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Heroes → Rubick → Last Spell ESP`.
