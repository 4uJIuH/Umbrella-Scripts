## Что умеет

Скрипт Item Eater позволяет выбирать и автоматически использовать поддерживаемые предметы. В загруженном файле находится Lua-скрипт; отдельный деобфусцированный VPK в каталог не включён.

- выбор предметов в меню и автоматическое поедание
- последняя версия и список доступных фраз опубликованы автором в Discord

## Установка

1. Поместите `dota_no_limit.lua` в `Umbrella\scripts` и перезагрузите скрипты.
2. Для обновлений и руководства откройте <a href="https://canary.discord.com/channels/408315082439917578/1530866882742063144/1530866948794220636" target="_blank" rel="noopener">публикацию автора в Discord</a> и <a href="https://umbrella-scripts.gitbook.io/tutorial/how-to-buy#ustanovka-polzovatelskikh-skriptov" target="_blank" rel="noopener">руководство по установке</a>.

# Dota No Limit (English)

## What it does

The Item Eater script lets you select and automatically use supported items. The supplied file is a Lua script; no separate deobfuscated VPK is included in this catalog.

- select items in the menu and enable automatic consumption
- the author posts the latest version and additional voice-line IDs on Discord

## Install

1. Place `dota_no_limit.lua` in `Umbrella\scripts` and reload scripts.
2. For updates and a guide, see the <a href="https://canary.discord.com/channels/408315082439917578/1530866882742063144/1530866948794220636" target="_blank" rel="noopener">author's Discord post</a> and the <a href="https://umbrella-scripts.gitbook.io/tutorial/how-to-buy#ustanovka-polzovatelskikh-skriptov" target="_blank" rel="noopener">custom-script installation guide</a>.
