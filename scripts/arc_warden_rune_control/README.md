## Что умеет

По нажатию бинда вызывает Tempest Double и отправляет его контролировать руну с помощью Magnetic Field, пока оригинальный герой может направиться к другой руне.

- Запускает контроль руны по бинду
- Использует Tempest Double и Magnetic Field
- Показывает статус управления руной и позволяет закрепить HUD

## Установка

1. Поместите `arcwagner.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Creeps → Arc moggers → Arc Warden Rune Control`.

# Arc Warden Rune Control (English)

## What it does

On a keybind, summons Tempest Double and sends it to control a rune with Magnetic Field while the original hero can head toward another rune.

- Starts rune control on a keybind
- Uses Tempest Double and Magnetic Field
- Displays rune-control status and includes a pinnable HUD

## Install

1. Place `arcwagner.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Creeps → Arc moggers → Arc Warden Rune Control`.
