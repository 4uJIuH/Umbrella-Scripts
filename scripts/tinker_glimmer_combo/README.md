## Что умеет

Скрипт для Tinker с настраиваемым комбо, помощником радиусов и модулем побега. Для побега можно выбрать предметы, использовать турели и задать направление к фонтану или курсору.

- Настраиваемое комбо с Glimmer Cape по бинду
- Модуль побега с выбором поддерживаемых предметов
- Настройки использования турелей и направления побега
- Помощник отображения радиусов

## Установка

1. Поместите `tincomb_v1.2.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Tinker → Tinker Misc Functions`.

# Tinker Glimmer Combo (English)

## What it does

A Tinker script with a configurable combo, range helper, and escape module. Choose escape items, optionally use turrets, and set the escape direction to the fountain or cursor.

- Configurable Glimmer Cape combo keybind
- Escape module with selectable supported items
- Options for turret usage and escape direction
- Range visualization helper

## Install

1. Place `tincomb_v1.2.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Tinker → Tinker Misc Functions`.
