## Что умеет

Скрипт для блокирования передвижения противника клонами Мипо с логикой построения блока тремя или четырьмя клонами.

- Распределяет клонов для блокирования выбранной цели
- Поддерживает варианты блока тремя и четырьмя клонами
- Настройки находятся в `General → Blocker → Meepo Blocker`

## Установка

1. Поместите `meepo_block.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Blocker → Meepo Blocker`.

# Meepo Block (English)

## What it does

A Meepo movement-blocking script with positioning logic for using three or four clones.

- Positions clones to block a selected target
- Supports three-clone and four-clone blocking patterns
- Settings are under `General → Blocker → Meepo Blocker`

## Install

1. Place `meepo_block.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `General → Blocker → Meepo Blocker`.
