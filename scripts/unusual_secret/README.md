## Что умеет

Меняет точку привязки некоторых эффектов на части тела героя. Это косметический скрипт; список поддерживаемых эффектов задаётся исходником.

- Выбор эффекта и части модели
- Версия исходника содержит собственное меню настроек

## Установка

1. Поместите `Unusual_Secret.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и найдите настройки в разделе визуальных скриптов.

# Unusual Secret (English)

## What it does

Changes the attachment point of supported effects to parts of a hero model. This is a cosmetic script; the supported effects are defined in its source.

- Select an effect and a model attachment point
- The source includes its own settings menu

## Install

1. Place `Unusual_Secret.lua` in `umbrella\scripts`.
2. Reload the Lua scripts and find its settings under visual scripts.
