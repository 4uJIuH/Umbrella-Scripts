# Tree Cutter

автоматически рубит ближайшие деревья Quelling Blade или Battle Fury / automatically chops nearby trees with Quelling Blade or Battle Fury

## Что умеет

Ищет ближайшее живое дерево в радиусе и отдаёт приказ срубить его. Можно работать постоянно или только при удержании бинда, ограничивать радиус дальностью применения и настраивать задержку.

- Поддержка Quelling Blade и Battle Fury с отдельными переключателями
- Режим постоянной работы или активации по бинду
- Настройка радиуса поиска и ограничения дальностью предмета
- Защита от повторных приказов и опция не прерывать канал

## Установка

1. Поместите `bf2.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Main → Tree Cutter`. Рекомендуемый радиус — 150–200.

# Tree Cutter (English)

## What it does

Finds the nearest living tree within range and issues a chop order. Choose continuous operation or a held keybind, clamp the search radius to item cast range, and configure the order delay.

- Separate Quelling Blade and Battle Fury toggles
- Continuous mode or keybind activation
- Configurable search radius and cast-range clamping
- Duplicate-order guard and an option not to interrupt channeling

## Install

1. Place `bf2.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Main → Tree Cutter`. A radius of 150–200 is recommended.
