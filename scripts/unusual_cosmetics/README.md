## Что умеет

Позволяет выбрать героя и предмет, а затем изменить его эффект в матче. Автор предупреждает о возможных сбросах эффектов.

- выбор героя и предмета из меню
- изменение необычного эффекта предмета во время матча

## Установка

1. Поместите `unusual_cosmetics.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты. Если эффекты сбрасываются или работают неправильно, сообщите об этом автору.

# Unusual Effects (English)

## What it does

Select a hero and item, then change its effect in a match. The author notes that effects may reset unexpectedly.

- select a hero and item from the menu
- change an item's unusual effect in a match

## Install

1. Place `unusual_cosmetics.lua` in `Umbrella\scripts`.
2. Reload Lua scripts. Report any effects that reset or behave incorrectly to the author.
