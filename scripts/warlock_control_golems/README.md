## Что умеет

После призыва големы атакуют ближайших врагов, а если подходящих целей нет — направляются продавливать линию. Панель показывает количество големов, их текущие задачи и оставшееся время жизни.

- Автоматически выбирает врагов для атаки в заданном радиусе
- Переключает големов на продвижение по линии при отсутствии целей
- Принудительный бинд для управления
- Панель статуса големов и времени их жизни

## Установка

1. Поместите `WarlockControlGolems.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Warlock → Main Settings → Control Golems`.

# Warlock Control Golems (English)

## What it does

After the golems are summoned, they attack nearby enemies or push a lane when no suitable targets are available. The overlay displays the number of golems, their current tasks, and remaining lifetime.

- Automatically selects enemies to attack within a configurable radius
- Switches golems to lane pushing when no targets are available
- Force-control keybind
- Golem status and lifetime overlay

## Install

1. Place `WarlockControlGolems.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Warlock → Main Settings → Control Golems`.
