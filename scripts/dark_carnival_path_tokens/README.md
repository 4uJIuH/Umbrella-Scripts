## Что умеет

Помогает планировать прохождение Dark Carnival: показывает требования по токенам для объектов на карте поезда и подходящих героев для комнат.

- Показывает, какие токены нужны для объектов на карте поезда
- Подсказывает героев, которыми удобнее быстрее открыть награды в каждой комнате
- Инвентарь OnHover отображается упрощённо

## Установка

1. Поместите `dark_carnival_path_tokens.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и откройте меню скрипта в `General`.

# Dark Carnival Path Tokens (English)

## What it does

Helps plan Dark Carnival progression by showing token requirements for objects on the train map and suitable heroes for each room.

- Shows the tokens required for objects on the train map
- Suggests heroes that can unlock each room's rewards more quickly
- The OnHover inventory tray is displayed in a simplified form

## Install

1. Place `dark_carnival_path_tokens.lua` in `umbrella\scripts`.
2. Reload Lua scripts and open the script menu under `General`.
