## Что умеет

Рисует предсказанную область приземления и радиус воздействия Firesnap Cookie с учётом бонусов к радиусу. Перед прыжком скрипт может повернуть Snapfire к курсору; автор отмечает возможный сбой при небольшом угле поворота.

- Предсказывает место приземления Firesnap Cookie
- Отображает радиус воздействия с учётом бонусов
- Может направлять прыжок к курсору
- Известное ограничение: поворот может не сработать при малом угле

## Установка

1. Поместите `snapfire_cookie_landing.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Main → Snapfire → Firesnap Cookie → Self Cookie`.

# Snapfire Cookie Landing (English)

## What it does

Draws the predicted landing area and Firesnap Cookie impact radius, accounting for radius bonuses. The script can turn Snapfire toward the cursor before jumping; the author notes that turning may fail for small angles.

- Predicts the Firesnap Cookie landing point
- Displays the impact radius with radius bonuses applied
- Can direct the jump toward the cursor
- Known limitation: turning may fail for a small angle

## Install

1. Place `snapfire_cookie_landing.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Main → Snapfire → Firesnap Cookie → Self Cookie`.
