## Что умеет

Записывает последовательность действий и позволяет воспроизвести её позднее.

- Управление записью и воспроизведением через меню и бинды
- Слоты записи, импорт и экспорт
- Настройки отображения и отладки

## Установка

1. Поместите `action_recorder.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте Scripts → Scripts → Action Recorder.

# Action Recorder (English)

## What it does

Records a sequence of actions and lets you replay it later.

- Control recording and playback from the menu and binds
- Recording slots, import, and export
- Display and debug settings

## Install

1. Place `action_recorder.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open Scripts → Scripts → Action Recorder.
