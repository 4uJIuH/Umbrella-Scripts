автоматически доставляет и использует Dust за Marci / automatically delivers and uses Dust as Marci

## Что умеет

Если замеченный противник в радиусе 400–1050 становится невидимым и у Marci нет Dust, скрипт запускает покупку и доставку через курьера, освобождая слот при необходимости. Автор предупреждает, что версия экспериментальная и может содержать ошибки.

- Настраиваемый радиус обнаружения от 400 до 1050
- Покупает Dust и вызывает курьера для доставки
- Может временно освободить слот, переложив предмет через курьера
- Автоматическое использование Dust и режим запуска цепочки по бинду

## Установка

1. Поместите `marci_dust_delivery.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Marci → Dusts` или `Scripts → Marci → Marci → Dusts`.

# Marci Dust Delivery (English)

## What it does

When a detected enemy within 400–1050 radius turns invisible and Marci has no Dust, the script starts a purchase and courier delivery, freeing an item slot through the courier if needed. The author describes this as experimental and warns that it may contain bugs.

- Configurable detection radius from 400 to 1050
- Buys Dust and calls the courier to deliver it
- Can temporarily free an inventory slot by transferring an item through the courier
- Automatic Dust use and a bind-triggered delivery mode

## Install

1. Place `marci_dust_delivery.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Marci → Dusts` or `Scripts → Marci → Marci → Dusts`.
