## Что умеет

Небольшой скрипт, который снимает блокировку объединения предмета при нажатии на него.

- Снимает lock с выбранного предмета по клику
- Настройки находятся в `General → Items → Combine Lock`

## Установка

1. Поместите `combine_lock_click.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Items → Combine Lock`.

# Combine Lock Click (English)

## What it does

A small script that removes an item combine lock when you click the item.

- Removes the combine lock from the selected item on click
- Settings are under `General → Items → Combine Lock`

## Install

1. Place `combine_lock_click.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `General → Items → Combine Lock`.
