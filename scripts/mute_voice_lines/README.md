## Что умеет

Отключает воспроизведение указанных голосовых фраз, отправленных через колесо чата. Список блокируемых ID задаётся в скрипте.

- приглушает выбранные voice lines
- позволяет добавлять нужные ID фраз в список

## Установка

1. Поместите `mute_voice_lines.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты и добавьте ID нужных фраз в список скрипта.

# Mute Voice Lines (English)

## What it does

Suppresses playback of selected voice lines sent through the chat wheel. The blocked IDs are configured in the script.

- mutes selected voice lines
- lets you add voice-line IDs to the block list

## Install

1. Place `mute_voice_lines.lua` in `Umbrella\scripts`.
2. Reload Lua scripts and add the desired voice-line IDs to the script's list.
