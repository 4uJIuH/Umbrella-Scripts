## Что умеет

Показывает KDA, нетворс и крипов в компактной панели. Нажмите на неё, чтобы раскрыть дополнительные показатели: GPM, XPM, крипов к 10-й минуте, участие в убийствах и урон по героям. Панель можно перетаскивать; настраиваются шрифт, размер, оформление и видимые строки. Автор: qhols (GitHub: @qhols, Discord: ur2m). Встроенная библиотека qLocalization: qfun (qfun_g9s).

- Основная и расширенная статистика матча в отдельной панели
- Сравнение со средними значениями Stratz для героя, ранга и минуты матча
- Перемещение панели и настройка шрифта, размера и строк
- Возможность скрыть стандартную панель статистики Dota

## Установка

1. Поместите `custom_stats.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Info Screen → Main → Custom Stats`.
4. Для сравнения получите бесплатный API-ключ на <a href="https://stratz.com/api" target="_blank" rel="noopener">stratz.com/api</a> и вставьте его в шестерёнку у пункта «Сравнение с другими».

# Custom Stats (English)

## What it does

Displays KDA, net worth, and creeps in a compact panel. Click it to expand more stats: GPM, XPM, creeps at 10 minutes, kill participation, and hero damage. The panel can be dragged, and its font, size, appearance, and visible rows are configurable. Author: qhols (GitHub: @qhols, Discord: ur2m). Bundled qLocalization library by qfun (qfun_g9s).

- Core and expanded match stats in a separate panel
- Comparison with Stratz averages for the hero, rank, and match minute
- Move the panel and customize its font, size, and rows
- Option to hide Dota's default stats panel

## Install

1. Place `custom_stats.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Info Screen → Main → Custom Stats`.
4. For comparisons, get a free API key from <a href="https://stratz.com/api" target="_blank" rel="noopener">stratz.com/api</a> and enter it in the gear next to “Compare with others”.
