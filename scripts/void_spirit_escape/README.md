## Что умеет

При удержании бинда направляет Void Spirit к фонтану и использует доступные способности и отмеченные предметы для выхода из опасности.

- Побег к своему фонтану по удержанию бинда
- Поддержка Pulse, Astral Step, Dissimilate и Remnant
- Настраиваемый список предметов для побега

## Установка

1. Поместите `void_spirit_escape.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Void Spirit → Main Settings → Escape Module`.

# Void Spirit Escape (English)

## What it does

While the keybind is held, directs Void Spirit toward the fountain and uses available abilities and selected items to escape.

- Escape toward your fountain while holding a keybind
- Supports Pulse, Astral Step, Dissimilate, and Remnant
- Configurable escape-item selection

## Install

1. Place `void_spirit_escape.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Void Spirit → Main Settings → Escape Module`.
