Повторно применяет настройки атмосферного тумана, отключённого Umbrella.

# Atmospheric Fog Restorer (English)

## What it does

Reapplies atmospheric fog settings that were disabled by Umbrella.

- Automatically restores fog at a configured interval
- No additional libraries required

## Install

1. Place `atmospheric_fog.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
