## Что умеет

Автоматически использует доступные сейв-предметы клона на основном герое в опасной ситуации. Пока заявлена реакция только на Black Hole.

- Проверяет предметы клона и применяет доступные способы спасения
- Автор предупреждает о поддержке только Black Hole

## Установка

1. Поместите `arc_warden_clone_safe_me.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и настройте скрипт в меню.

# Arc Warden Clone Safe Me (English)

## What it does

Automatically uses the clone's available save items on the main hero in danger. Black Hole is the only threat currently claimed as supported.

- Checks the clone's items and uses available save options
- The author warns that only Black Hole is supported

## Install

1. Place `arc_warden_clone_safe_me.lua` in `umbrella\scripts`.
2. Reload the Lua scripts and configure the script in its menu.
