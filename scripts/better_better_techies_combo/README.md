# Better Better Techies Combo

Бета-комбо для Techies. Начинает с Blast Off и ставит мины в полёте; автор рекомендует нажимать Blast Off вручную. Проверяет препятствия, включая деревья и Sprout.

- **Агрессивный** — использует Hex раньше для быстрого контроля
- **Макс. урон** — ждёт окончания стана от Blast Off и продолжает контроль Hex
- После комбо может блинкануться на фонтан или к выбранному союзнику

Функциональность бета-версии может меняться. Основа скрипта другого автора (Discord ID 875683534147321858) переработана sataroz и публикуется с разрешения. Автор доработки: sataroz (Discord: sataroz). Встроенная библиотека qLocalization: qfun (qfun_g9s).

## Установка и использование

1. Поместите `better_better_techies_combo.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Techies → Better Better Techies Combo` и включите скрипт.
4. Наведитесь на противника и зажмите настроенный бинд комбо.

# Better Better Techies Combo (English)

A beta combo script for Techies. It starts with Blast Off and places mines during flight; the author recommends casting Blast Off manually. It checks obstacles, including trees and Sprout.

- **Aggressive** — uses Hex earlier for quick control
- **Max Damage** — waits for Blast Off's stun to end, then continues control with Hex
- After the combo, can Blink to the fountain or a selected ally

Beta functionality may change. The script is based on another author's work (Discord ID 875683534147321858), revised by sataroz and published with permission. Updated by sataroz (Discord: sataroz). Bundled qLocalization library by qfun (qfun_g9s).

## Installation and use

1. Place `better_better_techies_combo.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Techies → Better Better Techies Combo` and enable it.
4. Hover over an enemy and hold the configured combo bind.
