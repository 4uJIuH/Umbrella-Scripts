## Что умеет

Ищет приоритетные цели — Tombstone, Phoenix Egg и различные вражеские варды — и направляет атаковать их Techies или подконтрольные юниты. Радиус и типы атакующих настраиваются.

- Приоритетные цели: Tombstone, Phoenix Egg и выбранные типы вардов
- Отдельные настройки для атаки героем и подконтрольными юнитами
- Настраиваемый радиус поиска

## Установка

1. Поместите `AutoFocus.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Settings → General → Units Controller → AutoFocus`.

# AutoFocus (English)

## What it does

Searches for priority targets such as Tombstone, Phoenix Egg, and enemy wards, then directs Techies or controllable units to attack them. Search radius and attacker types are configurable.

- Priority targets include Tombstone, Phoenix Egg, and selected wards
- Separate options for the hero and controllable units
- Configurable search radius

## Install

1. Place `AutoFocus.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Settings → General → Units Controller → AutoFocus`.
