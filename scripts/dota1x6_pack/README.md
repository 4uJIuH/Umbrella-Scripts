## Что умеет

Большой набор комбо для героев в кастомке 1x6. Библиотеки отдельно не требуются: qLocalization встроен в скрипт.

- Включает комбо Arc Warden, Invoker, Marci, Morphling, Muerta, Shadow Fiend и Tinker
- По описанию автора, поддерживает Q/W/E/R-легендарки у 24 героев
- Для Тинкера доступны Rearm Combo и Autofarm
- Удалите отдельные 1x6-скрипты перед установкой, чтобы избежать двойного выполнения

## Установка

1. Поместите `dota1x6_pack.lua` в `umbrella\scripts`.
2. Удалите отдельные 1x6-скрипты, если они установлены, затем перезагрузите скрипты.
3. Меню зависит от героя; у Тинкера настройки находятся в Rearm Combo и Autofarm.

# Dota 1x6 Pack (English)

## What it does

A large combo pack for heroes in the 1x6 custom game. No separate library files are needed; qLocalization is embedded.

- Includes combos for Arc Warden, Invoker, Marci, Morphling, Muerta, Shadow Fiend, and Tinker
- The author describes Q/W/E/R legendary support for 24 heroes
- Tinker has Rearm Combo and Autofarm sections
- Remove separate 1x6 scripts before installing to avoid duplicate execution

## Install

1. Place `dota1x6_pack.lua` in `umbrella\scripts`.
2. Remove separate 1x6 scripts if installed, then reload scripts.
3. Menus depend on the selected hero; Tinker's settings are under Rearm Combo and Autofarm.
