## Что умеет

Экспериментальный скрипт, который анализирует направление взгляда и движение врагов для оценки угроз. Автор делал его для себя; оценки эвристические и могут ошибаться.

- оценивает направление и перемещение противников
- помогает наблюдать за потенциальными угрозами
- результаты анализа следует считать экспериментальными

## Установка

1. Поместите `sentry.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты.

# Sentry (English)

## What it does

An experimental script that analyzes enemy facing and movement to estimate threats. The author built it for personal use; its heuristic assessments can be wrong.

- estimates enemy facing direction and movement
- helps observe potential threats
- treat the analysis as experimental

## Install

1. Place `sentry.lua` in `Umbrella\scripts`.
2. Reload Lua scripts.
