# Anti-Rubick

Защита выбранных способностей от кражи Рубиком / Protect selected spells from Rubick's Spell Steal

## Что умеет

Anti-Rubick помогает защитить важные способности от Spell Steal Рубика. После применения отмеченной способности скрипт может использовать выбранную способность-прикрытие, чтобы изменить последнее использованное заклинание. Список защитных и прикрывающих способностей, их приоритет и задержка настраиваются отдельно для каждого героя.

- Выбор способностей, которые нужно защитить, и способностей-прикрытий
- Перетаскивание для настройки приоритета способностей-прикрытий
- Настройка задержки применения и дистанции обнаружения Рубика
- Учет невидимого Рубика, Linken's Sphere и Mirror Shield
- Каналящиеся способности не защищаются

Автор: ⚔LegaXye禪 (Discord: legaxye)

## Установка

1. Поместите `anti_rubick.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте настройки `Scripts → General → Utility → Anti-Rubick → Spell Cover`.

# Anti-Rubick (English)

## What it does

Anti-Rubick helps protect important abilities from Rubick's Spell Steal. After a marked ability is used, the script can cast a selected cover ability to change the last spell used. Protected spells, cover spells, their priority, and the delay can be configured separately for each hero.

- Select abilities to protect and abilities to use as covers
- Drag cover abilities to set their priority
- Configure the cast delay and Rubick detection range
- Account for an unseen Rubick, Linken's Sphere, and Mirror Shield
- Channeled abilities are not protected

Author: ⚔LegaXye禪 (Discord: legaxye)

## Installation

1. Place `anti_rubick.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Scripts → General → Utility → Anti-Rubick → Spell Cover`.
