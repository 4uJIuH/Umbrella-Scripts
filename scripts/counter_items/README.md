## Что умеет

Анализирует состав и предметы противников и рекомендует контр-предметы. Это неофициальный снимок проекта; за актуальными файлами и библиотекой `ulib` обращайтесь к авторскому репозиторию.

- Учитывает способности, покупки врагов, героя игрока и предметы союзников
- Советы подстраиваются под роль и статистику OpenDota
- Для установки нужны `scripts/counter_items.lua` и папка `ulib` из репозитория автора

## Установка

1. Скачайте `scripts/counter_items.lua` и `ulib` из <a href="https://github.com/iseetwop/counteritems" target="_blank" rel="noopener">репозитория автора</a>.
2. Поместите Lua-файл в `umbrella\scripts`, а папку `ulib` — в `umbrella\scripts\ulib`.
3. Перезагрузите Lua-скрипты. Настройки: General → Counter Items.

# Counter Items (English)

## What it does

Analyzes enemy picks and items to suggest counters. This is an unversioned project snapshot; use the author's repository for current files and the required `ulib` library.

- Considers abilities, enemy purchases, your hero, and allied items
- Adapts recommendations to role and OpenDota statistics
- Installation requires `scripts/counter_items.lua` and the author's `ulib` folder

## Install

1. Download `scripts/counter_items.lua` and `ulib` from the <a href="https://github.com/iseetwop/counteritems" target="_blank" rel="noopener">author's repository</a>.
2. Place the Lua file in `umbrella\scripts` and `ulib` in `umbrella\scripts\ulib`.
3. Reload the Lua scripts. Settings: General → Counter Items.
