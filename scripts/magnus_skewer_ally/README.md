# Magnus Skewer Ally

Направляет Skewer во встроенном комбо Магнуса к выбранному союзнику.

- Выберите союзника в меню или наведитесь на него и нажмите бинд Lock Ally
- При наведении на врага отображаются линия к союзнику и статус дальности Skewer
- Если выбранный союзник погиб, скрипт может вернуть комбо к стандартному направлению на базу

Автор скрипта: sataroz (Discord: sataroz). Встроенная библиотека qLocalization: qfun (qfun_g9s).

## Установка и использование

1. Поместите `magnus_skewer_ally.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Magnus → Main Settings → Skewer Combo Settings`.
4. Включите Skewer To Ally и выберите союзника либо зафиксируйте его биндом Lock Ally.
5. Используйте обычную клавишу комбо.

# Magnus Skewer Ally (English)

Redirects Skewer in Magnus's built-in combo towards a selected ally.

- Select an ally in the menu, or hover over them and press the Lock Ally bind
- When hovering over an enemy, displays the line to the ally and Skewer range status
- If the selected ally dies, the script can return the combo to its default direction towards base

Script author: sataroz (Discord: sataroz). Bundled qLocalization library by qfun (qfun_g9s).

## Installation and use

1. Place `magnus_skewer_ally.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Heroes → Magnus → Main Settings → Skewer Combo Settings`.
4. Enable Skewer To Ally and select an ally, or lock one with the Lock Ally bind.
5. Use your regular combo key.
