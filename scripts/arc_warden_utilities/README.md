## Что умеет

Объединяет утилиты для Arc Warden: автоперекладывание предметов, блокирование хуков и перекатов клоном, Auto Spark и отображение радиуса притягивания рун. Автор указывает, что часть функций основана на работах других авторов.

- Перекладывает выбранные предметы между инвентарём и рюкзаком
- Перекладывает выбранные предметы в ранец на время перезарядки и возвращает их после окончания КД
- Пытается блокировать Meat Hook и Rolling Boulder клоном
- Содержит Auto Spark с настройкой каста только под стан
- Показывает настраиваемый радиус притягивания рун от Magnetic Field
- В описании исходника отдельно упомянуты работы <@737572019247251537> и <@757209868833914881>

## Установка

1. Поместите `arc_warden_utilities.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте Heroes → Hero List → Arc Warden → Утилиты.

# Arc Warden Utilities (English)

## What it does

Combines Arc Warden utilities: automatic item repositioning, clone-based hook and Rolling Boulder blocks, Auto Spark, and a rune-pull radius indicator. The author notes that some features are based on other authors' work.

- Moves selected items between inventory and backpack
- Moves selected items to the backpack while on cooldown and returns them when ready
- Attempts to block Meat Hook and Rolling Boulder with the clone
- Includes Auto Spark with an option to cast only under stun
- Displays the configurable rune-pull radius of Magnetic Field
- The supplied description credits work by <@737572019247251537> and <@757209868833914881>

## Install

1. Place `arc_warden_utilities.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open Heroes → Hero List → Arc Warden → Утилиты.
