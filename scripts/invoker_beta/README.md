## Что умеет

Бета-версия с автоматическим подбором комбинаций, улучшенным Auto Sunstrike, Auto Sphere и дополнительными игровыми функциями. Автор отмечает, что скрипт ещё не полностью протестирован.

- динамически подбирает прокаст под ситуацию
- Auto Sunstrike, Auto Sphere и быстрый Sun Strike под портретом
- есть экспериментальные кражи Roshan и Tormentor

## Установка

1. Поместите `invoker.lua` и `!_qLocalizer.lua` в `Umbrella\scripts`.
2. Отключите стандартный скрипт Invoker, чтобы избежать конфликтов.

Примечание: GitHub скачивает библиотеку как `_qLocalizer.lua`; переименуй её в `!_qLocalizer.lua` перед загрузкой Lua-скриптов.

# Invoker (beta) (English)

## What it does

A beta with automatic combo selection, improved Auto Sunstrike, Auto Sphere, and additional gameplay features. The author notes the script has not been fully tested.

- selects a combo dynamically for the current situation
- Auto Sunstrike, Auto Sphere, and a quick portrait Sun Strike
- experimental Roshan and Tormentor steals

## Install

1. Place `invoker.lua` and `!_qLocalizer.lua` in `Umbrella\scripts`.
2. Disable the standard Invoker script to avoid conflicts.

Note: GitHub downloads the library as `_qLocalizer.lua`; rename it to `!_qLocalizer.lua` before loading Lua scripts.
