## Что умеет

Панель отображает текущий ранг и прогресс до следующего уровня, статистику сессии и калькулятор количества игр до заданного MMR.

- Перемещаемая панель с настраиваемыми цветом и прозрачностью
- Считает победы и поражения текущей сессии
- Калькулятор оценивает число игр до цели по среднему MMR за матч
- Есть настраиваемое предупреждение о серии потерь

## Установка

1. Поместите `mmr_tracker_ultimate.lua` в `umbrella\scripts`.
2. Перезагрузите скрипты и откройте `Scripts → Other → MMR Tracker Ultimate`.

# MMR Tracker Ultimate (English)

## What it does

Displays your current rank and progress to the next tier, session statistics, and an estimate of games needed to reach a target MMR.

- Draggable panel with configurable colors and transparency
- Tracks wins and losses in the current session
- Estimates games to a target using the average MMR change per match
- Includes a configurable losing-streak warning

## Install

1. Place `mmr_tracker_ultimate.lua` in `umbrella\scripts`.
2. Reload scripts and open `Scripts → Other → MMR Tracker Ultimate`.
