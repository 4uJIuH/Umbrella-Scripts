автоматически стакает кемпы Tornado за Invoker / automatically stacks camps with Invoker's Tornado

## Что умеет

Планирует применение Tornado по времени падения крипов и корректирует тайминг на основе результата.

- Автоматический стак кемпов
- Учитывает выбранный кемп и время полёта
- Скрипт и обновления предоставляет автор в отдельном репозитории

## Установка

1. Установите `invoker_autostack.lua` через менеджер или скачайте из <a href="https://github.com/gdhost4-eng/umbrella-invoker-autostack/releases" target="_blank" rel="noopener">официальных релизов</a>.
2. Поместите файл в `umbrella\scripts` и перезагрузите Lua-скрипты.
3. Настройте управление в разделе Invoker.

# Invoker AutoStack (English)

## What it does

Schedules Tornado around creep drop timing and adjusts the timing based on the result.

- Automatic camp stacking
- Accounts for the selected camp and travel time
- The author maintains the script and updates in a separate repository

## Install

1. Install `invoker_autostack.lua` through the manager or download it from the author's <a href="https://github.com/gdhost4-eng/umbrella-invoker-autostack/releases" target="_blank" rel="noopener">official releases</a>.
2. Place the file in `umbrella\scripts` and reload Lua scripts.
3. Configure the controls under Invoker.
