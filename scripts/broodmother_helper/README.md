## Что умеет

Обновлённый помощник Broodmother на основе исходной версии другого автора. Добавляет автоматическое управление пауками, преследование врагов и исправления Bloodthorn/Orchid.

- Автоматическое следование за героем и преследование противников
- Пауки могут фармить, когда Broodmother атакует крипов
- Исправлена логика применения Bloodthorn и Orchid

## Установка

1. Поместите `broodmother_helper.lua` в `umbrella\scripts`.
2. Перезагрузите скрипты и откройте `Heroes → Hero List → Broodmother`.

# Broodmother Helper (English)

## What it does

An updated Broodmother helper based on another author's initial version. Adds automatic spider control, enemy chasing, and Bloodthorn/Orchid fixes.

- Automatically follows the hero and chases enemies
- Spiders can farm while Broodmother is attacking creeps
- Fixes smart Bloodthorn and Orchid usage

## Install

1. Place `broodmother_helper.lua` in `umbrella\scripts`.
2. Reload scripts and open `Heroes → Hero List → Broodmother`.
