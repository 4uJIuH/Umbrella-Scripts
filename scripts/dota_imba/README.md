## Что умеет

Добавляет кнопки для повторного бесплатного ролла рун, выбора трёх одинаковых рун и получения предмета из указанного слота сокровищницы. Скрипт рассчитан на соответствующую кастомную игру.

- Бесплатный повторный ролл рун
- Выбор одной и той же руны до трёх раз
- Выбор награды по номеру слота сокровищницы

## Установка

1. Поместите `dota_imba.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → dota imba → Main` в поддерживаемой кастомной игре.

# Dota Imba (English)

## What it does

Adds buttons to reroll runes for free, select the same rune three times, and claim a treasure reward by slot number. This script is intended for the corresponding custom game.

- Free rune rerolls
- Select the same rune up to three times
- Claim a treasure reward by slot number

## Install

1. Place `dota_imba.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → dota imba → Main` in the supported custom game.
