## Что умеет

Открывает набор встроенных игр и утилит: крестики-нолики, шахматы, пасьянс, сапёр, морской бой, 2048, казино, калькулятор и виджет погоды.

- Включение каждой игры отдельным переключателем
- Игры отображаются внутриигровыми панелями
- Виджет погоды получает данные через интернет

## Установка

1. Поместите `mini_games.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → Мини-игры`.

# Mini Games (English)

## What it does

Opens a collection of built-in games and utilities: tic-tac-toe, chess, solitaire, minesweeper, battleship, 2048, casino, calculator, and a weather widget.

- Each game can be toggled separately
- Games are displayed in in-game panels
- The weather widget retrieves data over the internet

## Install

1. Place `mini_games.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Utility → Мини-игры`.
