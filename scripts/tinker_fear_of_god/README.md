## Что умеет

Скрипт для Тинкера в кастомных играх с комбо, настройками предметов и побегом. Совместим только с патчем 7.32; для 7.28 не адаптирован.

- Комбо по бинду с настройками способностей и предметов
- Отдельные настройки побега и перемещения
- Только патч 7.32 — не использовать как адаптацию для 7.28

## Установка

1. Поместите `fear_of_god.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Tinker → Tinker Fear of God Combo`.

# Tinker Fear of God Combo (English)

## What it does

A Tinker script for custom games with combo, item, and escape settings. It is for patch 7.32 only and has not been adapted for 7.28.

- Keybound combo with configurable abilities and items
- Separate escape and movement settings
- Patch 7.32 only — not adapted for 7.28

## Install

1. Place `fear_of_god.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Tinker → Tinker Fear of God Combo`.
