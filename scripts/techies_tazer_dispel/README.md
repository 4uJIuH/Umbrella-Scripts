## Что умеет

Дополнение для Techies, которое использует взрыв Reactive Tazer для автоматического диспела. Основа скрипта написана по просьбе Yerka, который доработал её и поделился скриптом.

- отслеживает подходящий момент для взрыва Reactive Tazer
- автоматически применяет диспел по условиям скрипта

## Установка

1. Поместите `techies_tazer_dispel.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты и проверьте настройки Techies.

# Techies Tazer Dispel (English)

## What it does

A Techies utility that uses Reactive Tazer's explosion to automatically dispel. The base script was written at Yerka's request, then extended and shared by him.

- tracks when Reactive Tazer should be detonated
- automatically applies a dispel when the script's conditions are met

## Install

1. Place `techies_tazer_dispel.lua` in `Umbrella\scripts`.
2. Reload Lua scripts and check the Techies settings.
