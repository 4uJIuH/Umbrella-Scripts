## Что умеет

Скрипт автоматизирует комбо Windranger по бинду и предлагает настройки способностей, поиска цели, Shackleshot и визуальных индикаторов.

- Бинд комбо и выбор способностей для применения
- Настройка поиска цели около курсора
- Параметры Shackleshot и проверка Linken's Sphere
- HUD состояния, индикатор цели и конус Shackleshot

## Установка

1. Поместите `Windranger.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Windranger → Windranger Combo`.

# Windranger Combo (English)

## What it does

Automates a Windranger combo on a keybind and provides options for abilities, target search, Shackleshot, and visual indicators.

- Combo keybind and selectable abilities
- Configure target search around the cursor
- Shackleshot options and Linken's Sphere check
- Combo HUD, target indicator, and Shackleshot cone

## Install

1. Place `Windranger.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Windranger → Windranger Combo`.
