# Обновление v2.10.5

- Дата выхода обновления показывается рядом с номером версии («2.10.3 → 2.10.4 · сегодня») и больше не наезжает на оценки и кнопку «Обновить».

# Обновление v2.10.4

- Скрипты разных авторов с одинаковым именем файла (Windranger Powershot и Windranger Combo) больше не перезаписывают друг друга: каждый сохраняется в свой файл, а установка одного не отмечает другой установленным.
- Проверка обновлений стала точнее: скрипты скачиваются в свежей версии без кэша GitHub, версия читается только из своей строки, а локальные файлы пересканируются при каждой проверке.
- Автообновление ставит только то, что действительно установлено, и только когда оно включено.
- Поиск героев понимает сокращения и прозвища: wr, qop, квопа, wk, скелет, am и другие, а также запрос, набранный в русской раскладке («цк» = wr). Общий поиск находит скрипты по этим сокращениям.

# Обновление v2.10.3

- Если установка или обновление не удалось, кнопка становится «Повторить», а причина ошибки выводится красным на карточке и на странице скрипта.
- При обновлении всех скриптов баннер показывает прогресс («Обновление: N из M»), а кнопка «Обновить все» неактивна до конца.
- На странице скрипта при ожидающем или идущем обновлении показан список изменений новой версии.
- Стрелки перемещают выбор по списку, Enter открывает выбранный скрипт.
- Поиск не учитывает регистр для русских букв.
- Установка показывает прогресс по файлам («Установка 2/3»).
- Удаление скрипта удаляет его файлы и резервные копии; файлы, общие с другими установленными скриптами, сохраняются.

# Обновление v2.9.0

- Для пакетов с манифестом проверяются имена файлов, ссылки и размер JSON; ZIP/RAR без списка файлов по-прежнему скачиваются для ручной установки.

**Обновление v2.0.0**

- Script Market стал новым Script Manager: каталог, файл `script_manager.lua` и тег `script-manager-v*` сохранены, поэтому прежняя установка сможет обновиться на новую версию.
