## Что умеет

Считает выгодный маршрут по лесным лагерям и волнам крипов с учётом награды, времени перемещения и скорости зачистки.

- Greedy, DFS Optimal и Beam Search
- учёт тумана войны, респауна лагерей, AoE и таймингов стакания
- HUD с эффективностью, таймлайном и маршрутом на карте
- импорт и экспорт настроек

## Установка

1. Поместите `farm_pattern_2_5.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты.

# Farm Pattern 2.5 (English)

## What it does

Calculates routes through jungle camps and creep waves using rewards, travel time, and estimated clear speed.

- Greedy, DFS Optimal, and Beam Search algorithms
- accounts for fog of war, camp respawns, AoE, and stack timing
- HUD with efficiency, timeline, and map route
- imports and exports settings

## Install

1. Place `farm_pattern_2_5.lua` in `Umbrella\scripts`.
2. Reload Lua scripts.
