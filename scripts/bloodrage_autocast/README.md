# Bloodrage AutoCast

Автоматически применяет Bloodrage у Bloodseeker / Automatically casts Bloodrage on Bloodseeker

## Что умеет

Автоматически применяет первую способность Bloodseeker, когда она готова. Автокаст переключается биндом, который по умолчанию назначен на F; в настройках также можно ограничить работу Bloodseeker и включить статусную надпись.

- Проверяет героя, наличие способности, готовность и возможность её применить
- Включает и выключает автокаст переключаемым биндом (по умолчанию F)
- Показывает текущий статус работы, если включено отображение статуса

Автор: zвeзdы уnaлu v лужу (Discord: rarimember).

## Установка

1. Поместите `bloodrage.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Scripts → Bloodrage` и настройте переключаемый бинд.

# Bloodrage AutoCast (English)

## What it does

Automatically casts Bloodseeker's first ability when it is ready. Auto-cast is controlled by a toggle bind, assigned to F by default; the settings also let you restrict it to Bloodseeker and enable an on-screen status.

- Checks the hero, ability availability, cooldown, and castability
- Toggles auto-cast with a configurable bind (F by default)
- Displays the current status when the status option is enabled

Author: zвeзdы уnaлu v лужу (Discord: rarimember).

## Installation

1. Place `bloodrage.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Scripts → Scripts → Bloodrage` and configure the toggle bind.
