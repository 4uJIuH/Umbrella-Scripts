## Что умеет

Панель для составления последовательностей способностей и предметов Инвокера. Автор отмечает, что пока не смог добиться надёжного сохранения новых комбо как комбинаций по умолчанию.

- Добавление способностей и предметов в строку комбо
- Изменение порядка перетаскиванием без пересоздания всей комбинации
- Нажмите на заклинание, чтобы исключить его из комбо
- Сохранение новых комбинаций по умолчанию пока не решено; проверяйте, что настройки сохраняются

## Установка

1. Поместите `Invoker_Combo_Panel.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте настройки в разделе `Heroes → Hero List → Invoker`.

# Invoker Combo Panel (English)

## What it does

A panel for building Invoker ability and item sequences. The author reports that reliably saving custom combos as defaults is still unresolved.

- Add abilities and items to the combo sequence
- Reorder entries by dragging and dropping
- Click a spell to exclude it from the combo
- Saving custom combos as defaults is unresolved; verify that settings persist

## Install

1. Place `Invoker_Combo_Panel.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open the settings under `Heroes → Hero List → Invoker`.
