## Что умеет

Отображает кулдауны способностей и предметов в интерфейсе. Враг должен хотя бы раз попасть в обзор, чтобы скрипт мог учитывать его способность или предмет, ушедшие в перезарядку в тумане.

- Показывает перезарядки вражеских способностей и предметов
- Работает также с нейтральными крипами и телепортами
- Не раскрывает кулдаун, если враг не был замечен до его начала

## Установка

1. Поместите `enemy_cooldowns.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты и настройте отображение в `Info Screen → Main → Heroes Overlay → Main → Selected Enemy Cooldowns`.

# Enemy Cooldowns (English)

## What it does

Displays ability and item cooldowns in the interface. An enemy must have been seen at least once for the script to track an ability or item that went on cooldown in fog.

- Shows cooldowns for enemy abilities and items
- Also works with neutral creeps and teleport scrolls
- Does not reveal a cooldown if the enemy was never observed before it began

## Install

1. Place `enemy_cooldowns.lua` in `umbrella\scripts`.
2. Reload Lua scripts and configure the display under `Info Screen → Main → Heroes Overlay → Main → Selected Enemy Cooldowns`.
