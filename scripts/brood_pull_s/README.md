## Что умеет

По бинду выполняет отвод крипов на выбранные линии и показывает подсказки по точкам и времени. Автор сообщает, что скрипт адаптируется для обеих сторон.

- Выбор режима удержания или переключения бинда
- Настройка количества линий для отвода
- Отображение линий и статуса отвода
- Маршруты для Radiant и Dire

## Установка

1. Поместите `brood_pull_s.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Lane Pull → lane_pull`.

# Brood Pull S (English)

## What it does

On a keybind, performs lane pulls and displays waypoint and timing hints. The author says the script adapts to both sides.

- Hold or toggle keybind modes
- Configurable number of lanes to pull
- Displays pull lanes and status
- Routes for Radiant and Dire

## Install

1. Place `brood_pull_s.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Lane Pull → lane_pull`.
