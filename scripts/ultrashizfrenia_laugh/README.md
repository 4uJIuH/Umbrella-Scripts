## Что умеет

Автоматически выполняет `/laugh` примерно раз в 16 секунд, пока скрипт включён и ваш герой жив. Функция включена по умолчанию.

- Автоматическая игровая команда `/laugh`
- Переключатель включения в меню

## Установка

1. Поместите `ultrashizfrenia_laugh.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Miscellaneous → In Game → ULTRASHIZOFRENIA laugh` и отключите функцию, если не хотите автоматический смех.

# ULTRASHIZOFRENIA Auto Laugh (English)

## What it does

Automatically executes `/laugh` about every 16 seconds while enabled and your hero is alive. The feature is enabled by default.

- Automatic in-game `/laugh` command
- Enable toggle in the menu

## Install

1. Place `ultrashizfrenia_laugh.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Miscellaneous → In Game → ULTRASHIZOFRENIA laugh` and disable the feature if you do not want automatic laughter.
