## Что умеет

Тренажёр с ежедневными уроками, заданиями, стриком, опытом и адаптивной сложностью. Для синхронизации стрика требуется интернет.

- 10 заданий в ежедневном уроке; ошибки возвращают задание в конец
- Стрик по московскому времени, серверная синхронизация и до двух заморозок
- 12 юнитов обучения и шесть типов заданий
- Опыт, уровни, календарь, адаптивная сложность и тренировка
- Окно можно открыть из меню Scripts → Utility → Lualingo

## Установка

1. Скачайте и распакуйте `lualingo.zip` в `umbrella\scripts`.
2. Убедитесь, что после распаковки доступны `lualingo.lua` и `lualingo\tasks.lua`.
3. Перезагрузите Lua-скрипты.
4. Откройте `Scripts → Utility → Lualingo` и выберите «Открыть Lualingo».

# Lualingo (English)

## What it does

A practice tool with daily lessons, exercises, streaks, experience, and adaptive difficulty. Internet access is required to sync the streak.

- 10 tasks in a daily lesson; missed answers return to the end
- Moscow-time streak, server synchronization, and up to two freezes
- 12 learning units and six exercise types
- Experience, levels, calendar, adaptive difficulty, and practice
- Open the window from Scripts → Utility → Lualingo

## Install

1. Download and extract `lualingo.zip` into `umbrella\scripts`.
2. Make sure the extracted `lualingo.lua` and `lualingo\tasks.lua` are both present.
3. Reload the Lua scripts.
4. Open `Scripts → Utility → Lualingo` and select Open Lualingo.
