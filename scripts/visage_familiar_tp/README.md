# Visage Familiar TP Helper

Синхронизирует Recall гаргулий при телепортации Визажа и помогает увести их перед кастом в безопасную зону — вглубь леса или за союзную вышку. Автор: ! M0RC1 (Discord: wh1teray).

## Возможности

- Одновременный Recall всех гаргулий при обнаружении телепорта Визажа.
- Поиск безопасного места в лесу или за ближайшей союзной вышкой.
- Настраиваемое максимальное время отхода от 0,5 до 3 секунд.
- Отображение статуса и перезарядки в интерфейсе.

## Установка

1. Нажмите «Установить» в Script Manager или поместите `garguliatp.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Visage → Familiar TP Helper`.

# Visage Familiar TP Helper (English)

Synchronizes Familiar Recall when Visage teleports and helps move familiars to a safer location before casting, among trees or behind an allied tower. Author: ! M0RC1 (Discord: wh1teray).

## Features

- Starts Recall on all familiars together when Visage begins teleporting.
- Looks for a safe location in the trees or behind a nearby allied tower.
- Configurable maximum retreat time from 0.5 to 3 seconds.
- Optional status and cooldown display.

## Installation

1. Click Install in Script Manager or place `garguliatp.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Visage → Familiar TP Helper`.
