## Что умеет

Visage Familiar TP Helper помогает синхронно применить Recall к гаргульям при телепортации Визажа и заранее отвести их в безопасное место. Автор: ! M0RC1 (Discord: wh1teray).

- Отслеживает телепортацию Визажа и синхронно запускает Recall на гаргульях
- Ищет безопасную позицию в лесу или за ближайшей союзной вышкой
- Настраиваемый лимит отхода 0,5–3 секунды и отображение статуса с перезарядкой

## Установка

1. Нажмите «Установить» в Script Manager или поместите garguliatp.lua в umbrella\scripts.
2. Перезагрузите Lua-скрипты.
3. Откройте Heroes → Hero List → Visage → Familiar TP Helper.

# Visage Familiar TP Helper (English)

## What it does

Visage Familiar TP Helper synchronizes Familiar Recall when Visage teleports and moves familiars to a safer location beforehand. Author: ! M0RC1 (Discord: wh1teray).

- Detects Visage teleporting and starts Recall on familiars together
- Looks for a safe position among trees or behind a nearby allied tower
- Configurable 0.5–3 second retreat limit and optional status/cooldown display

## Install

1. Click Install in Script Manager or place garguliatp.lua in umbrella\scripts.
2. Reload Lua scripts.
3. Open Heroes → Hero List → Visage → Familiar TP Helper.
