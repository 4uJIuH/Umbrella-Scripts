## Что умеет

Перекладывает выбранные предметы между ячейками инвентаря при использовании Bottle. Можно указать предметы, которые не нужно трогать.

- Обрабатывает только основные слоты
- Список исключений настраивается в меню
- Восстанавливает расположение предметов после цикла

## Установка

1. Поместите `botle.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте Scripts → Other → Абуз ботла.

# Botle Abuse (English)

## What it does

Moves selected items between inventory slots when Bottle is used. Items to leave untouched can be selected in the menu.

- Operates only on the main inventory slots
- Configurable item exclusion list
- Restores item positions after the sequence

## Install

1. Place `botle.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open Scripts → Other → Абуз ботла.
