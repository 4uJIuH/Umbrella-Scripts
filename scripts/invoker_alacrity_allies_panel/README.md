# Invoker Alacrity Allies Panel

выбирает союзников для перенаправления Alacrity / selects allies to receive redirected Alacrity casts

## Что умеет

Добавляет панель выбора союзников. При применении Alacrity перенаправляет способность на ближайшего отмеченного союзника рядом; по умолчанию все союзники выключены.

- Можно отдельно включать и выключать союзников в панели
- При применении Alacrity выбирает ближайшего отмеченного подходящего союзника
- Если поблизости нет выбранных союзников, обычное применение способности не блокируется

## Установка

1. Поместите `invoker_alacrity_allies_panel.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Invoker → Alacrity Allies Panel` и выберите союзников.

# Invoker Alacrity Allies Panel (English)

## What it does

Adds an ally-selection panel. When Alacrity is cast, it redirects the spell to the nearest enabled ally nearby; all allies are disabled by default.

- Enable or disable each ally individually in the panel
- Redirects Alacrity to the nearest enabled eligible ally
- If no selected ally is nearby, the normal cast is not blocked

## Install

1. Place `invoker_alacrity_allies_panel.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open `Heroes → Hero List → Invoker → Alacrity Allies Panel` and select allies.
