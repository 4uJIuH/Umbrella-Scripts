## Что умеет

Версия скрипта для Shadow Fiend с дополнительными настройками KOTL и Octarine, а также защитой накопленных душ при использовании предметов и телепортации.

- использует способность с учётом остаточного времени эффекта
- блокирует некоторые действия, которые могут сбросить души
- содержит настройки связки с Keeper of the Light

## Установка

1. Поместите `sf_feast_of_souls_abuse.lua` в `Umbrella\scripts`.
2. Перезагрузите Lua-скрипты и настройте раздел `Heroes → Shadow Fiend → Feast of Souls Abuse`.

# SF Feast of Souls Abuse (English)

## What it does

A Shadow Fiend script with KOTL and Octarine options and protections for stored souls when using items or teleporting.

- uses the ability based on the remaining effect duration
- blocks selected actions that could remove stored souls
- includes Keeper of the Light synergy settings

## Install

1. Place `sf_feast_of_souls_abuse.lua` in `Umbrella\scripts`.
2. Reload scripts and configure `Heroes → Shadow Fiend → Feast of Souls Abuse`.
