## Что умеет

Отображает предполагаемую область действия ультимейта Shadow Fiend. Режим показа, цвет, толщину и тип эффекта можно настроить.

- Круг, пульсирующая пунктирная линия или кольцевой эффект
- Показ по готовности способности, во время применения или постоянно
- Настраиваемые цвет и толщина

## Установка

1. Поместите `sf_requiem_radius.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Heroes → Hero List → Shadow Fiend → Requiem Radius → Main`.

# Shadow Fiend Requiem Radius (English)

## What it does

Displays the estimated area of Shadow Fiend's ultimate. Configure when it is shown, its color, thickness, and visual effect.

- Circle, pulsing dashed line, or ring effect
- Show when the ability is ready, while casting, or always
- Configurable color and thickness

## Install

1. Place `sf_requiem_radius.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Heroes → Hero List → Shadow Fiend → Requiem Radius → Main`.
