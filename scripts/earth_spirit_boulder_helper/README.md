## Что умеет

Помогает прицеливаться Rolling Boulder: отображает траекторию и отмечает Stone Remnant, который продлевает дальность. Можно настроить цвета и показывать разметку по переключателю или бинду.

- Отображает траекторию Rolling Boulder
- Показывает дальность с учётом Stone Remnant
- Настраиваемые цвета линии и расширенной траектории
- Включение разметки переключателем или биндом

## Установка

1. Поместите `earth_spirit_boulder_helper.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → HEROES → Earth Spirit → Boulder Helper → Settings`.

# Earth Spirit Boulder Helper (English)

## What it does

Helps aim Rolling Boulder by displaying its path and marking a Stone Remnant that extends its range. Configure the colors and show the overlay with a switch or keybind.

- Displays the Rolling Boulder path
- Shows extended range when using a Stone Remnant
- Configurable path and extended-range colors
- Toggle the overlay with a switch or keybind

## Install

1. Place `earth_spirit_boulder_helper.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → HEROES → Earth Spirit → Boulder Helper → Settings`.
