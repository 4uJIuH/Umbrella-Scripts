## Что умеет

Отображает радиус действия уже брошенного Dust и обнаруженные им цели. Можно выбрать вид частицы и настроить цвета для союзных и вражеских глаз, а также самой области.

- Показывает область действия применённого Dust
- Настраиваемые цвета частиц и обнаруженных целей
- Выбор эффекта радиуса из доступного списка

## Установка

1. Поместите `dust_radius.lua` в `umbrella\scripts`.
2. Убедитесь, что включены серверные скрипты и основной скрипт отображения радиусов.
3. Перезагрузите Lua-скрипты.
4. Откройте `Info Screen → Main → Radius → Main → Others Settings → Dust Radius`.

# Dust Radius (English)

## What it does

Displays the area of an already-cast Dust and the targets it reveals. Choose the particle effect and customize colors for allied and enemy eyes as well as the radius itself.

- Shows the area of an already-used Dust
- Customizable colors for particles and revealed targets
- Choose a radius effect from the available particle list

## Install

1. Place `dust_radius.lua` in `umbrella\scripts`.
2. Make sure server scripts and the main radius-display script are enabled.
3. Reload Lua scripts.
4. Open `Info Screen → Main → Radius → Main → Others Settings → Dust Radius`.
