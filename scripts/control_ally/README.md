## Что умеет

Пока зажата клавиша Combo Key вашего героя, скрипт управляет выбранным союзным героем, которым можно командовать через shared control.

- Использует способности и предметы союзного героя по выбранной цели
- Поддерживает выбор цели у курсора и автоматический выбор по оценке угрозы
- В зависимости от героя может применять Blink, сбивать Linken's и выполнять динамическое комбо

## Установка

1. Поместите `control_ally.lua` в `umbrella\scripts` и перезагрузите Lua-скрипты.
2. Включите `Heroes → Settings → General → Units Controller → Control Ally` и выберите союзника.
3. Назначьте Combo Key своему герою; удерживайте её и наведите курсор на цель либо используйте Auto Score.

# Control Ally (English)

## What it does

While you hold your hero's Combo Key, the script controls a selected allied hero that you can command through shared control.

- Uses the allied hero's abilities and items against the selected target
- Supports cursor targeting and automatic threat-based target selection
- Depending on the hero, can initiate with Blink, break Linken's, and run dynamic combos

## Install

1. Place `control_ally.lua` in `umbrella\scripts` and reload Lua scripts.
2. Enable `Heroes → Settings → General → Units Controller → Control Ally` and select an ally.
3. Bind your hero's Combo Key; hold it and point at a target, or use Auto Score.
