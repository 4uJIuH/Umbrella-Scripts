## Что умеет

Показывает оставшееся время действия глифа защиты над затронутыми строениями и крипами. Автор отмечает, что скрипт написан с помощью ИИ.

- Полоса прогресса и оставшееся время над башнями, другими строениями и крипами
- Фильтры для крипов, строений, союзников и врагов
- Группировка близких таймеров отдельно для крипов и строений с отображением количества
- Настройка размера, смещения, шрифта, цветов, тени и свечения

## Установка

1. Поместите `glyph_timer.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → Glyph Timer`.

# Glyph Timer (English)

## What it does

Displays the remaining glyph protection duration above affected buildings and creeps. The author notes that the script was written with AI assistance.

- Progress bar and remaining time above towers, other buildings, and creeps
- Filters for creeps, buildings, allies, and enemies
- Clusters nearby timers separately for creeps and buildings, with a count
- Configurable size, offset, font, colors, shadow, and glow

## Install

1. Place `glyph_timer.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Main → Glyph Timer`.
