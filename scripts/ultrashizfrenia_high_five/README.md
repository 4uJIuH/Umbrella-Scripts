## Что умеет

Если союзный герой в радиусе запросил high five, скрипт применяет способность Plus High Five. Переключатель выключен по умолчанию; скрипт использует XHelpers.

- Обнаруживает запрос high five поблизости
- Автоматически применяет Plus High Five
- Имеет переключатель включения

## Установка

1. Поместите `ultrashizfrenia_high_five.lua` в `umbrella\scripts`.
2. Убедитесь, что доступны требуемые XHelpers.
3. Перезагрузите Lua-скрипты.
4. Откройте `Miscellaneous → In Game → ULTRASHIZOFRENIA Auto High Five`.

# ULTRASHIZOFRENIA Auto High Five (English)

## What it does

When an allied hero nearby requests a high five, the script casts Plus High Five. The enable toggle is off by default; the script uses XHelpers.

- Detects nearby high-five requests
- Automatically casts Plus High Five
- Includes an enable toggle

## Install

1. Place `ultrashizfrenia_high_five.lua` in `umbrella\scripts`.
2. Make sure the required XHelpers are available.
3. Reload Lua scripts.
4. Open `Miscellaneous → In Game → ULTRASHIZOFRENIA Auto High Five`.
