## Что умеет

Временно отключает голос и текст игрока, отправившего фразу из колеса чата, чтобы приглушить её воспроизведение. При отключении скрипта восстанавливает исходные настройки мутов.

- Обрабатывает голосовые фразы из колеса чата, включая фразы Dota Plus
- При желании выводит заблокированные фразы в консоль
- Возвращает исходное состояние мута после фразы

## Установка

1. Поместите `MuteAllVoicePhrases.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Miscellaneous → In Game → Mute Voice Phrases`.

# Mute All Voice Phrases (English)

## What it does

Temporarily mutes the voice and text of the player who sent a chat-wheel phrase to suppress its playback. Restores the previous mute state when the script is disabled.

- Handles chat-wheel voice phrases, including Dota Plus lines
- Optionally logs muted phrases to the console
- Restores the previous mute state after a phrase

## Install

1. Place `MuteAllVoicePhrases.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Miscellaneous → In Game → Mute Voice Phrases`.
