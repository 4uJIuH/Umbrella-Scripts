## Что умеет

Использует Bulldoze перед столкновением, может нажать Nether Strike и активировать предметы. Дополнительно умеет ставить игру на паузу и отправлять настраиваемый числовой отсчёт в чат.

- Опциональные Bulldoze и Nether Strike при столкновении
- Автоматическое применение выбранных предметов
- Отдельные переключатели паузы и сообщений в командный или общий чат
- Чат-отсчёт включён по умолчанию в исходнике; отключите его, если не хотите отправлять сообщения

## Установка

1. Поместите `bara.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Отключите Auto Pause On Impact и 1000-7 Chat Countdown, если эти действия не нужны.

# Spirit Breaker Combo & Ghoul 1000-7 (English)

## What it does

Uses Bulldoze before impact, can cast Nether Strike, and activates items. It can also pause the game and send a configurable numeric countdown to chat.

- Optional Bulldoze and Nether Strike at impact
- Automatically uses selected items
- Separate toggles for pausing and sending messages to team or all chat
- Chat countdown is enabled by default in the source; disable it if you do not want messages sent

## Install

1. Place `bara.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Disable Auto Pause On Impact and 1000-7 Chat Countdown if you do not want those actions.
