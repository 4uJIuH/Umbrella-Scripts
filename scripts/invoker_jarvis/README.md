## Что умеет

Голосом вызывает и применяет способности и предметы, а также запускает заранее настроенные комбо Invoker.

- Команды для способностей, предметов, сфер, телепорта и прокачки
- Запуск комбо из меню Invoker
- Скрипт Lua можно установить отдельно; для голосового управления также требуется Jarvis.exe из оригинального репозитория

## Установка

1. Установите `invoker_jarvis.lua` через менеджер или скачайте его из <a href="https://github.com/gdhost4-eng/umbrella-invoker-jarvis/releases" target="_blank" rel="noopener">официального раздела Releases</a>.
2. Чтобы включить голосовые команды, скачайте и запустите `Jarvis.exe` только из оригинального репозитория автора.
3. В игре откройте Heroes → Invoker → Jarvis.

# Invoker Jarvis (English)

## What it does

Uses voice to invoke and cast abilities and items, and to start preconfigured Invoker combos.

- Commands for abilities, items, orbs, teleport, and leveling
- Starts combos from the Invoker menu
- The Lua script can be installed separately; voice control also requires Jarvis.exe from the original repository

## Install

1. Install `invoker_jarvis.lua` through the manager or download it from the author's <a href="https://github.com/gdhost4-eng/umbrella-invoker-jarvis/releases" target="_blank" rel="noopener">official Releases</a>.
2. For voice commands, download and run `Jarvis.exe` only from the author's original repository.
3. In game, open Heroes → Invoker → Jarvis.
