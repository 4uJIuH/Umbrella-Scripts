## Что умеет

Внешний проект для Lina: добавляет решения, которым нужны состояние между кадрами и знания о герое. Исходники и релизы поддерживаются автором в отдельном репозитории.

- Комбо и выбор целей с проверкой возможности убийства, включая защитные модификаторы
- Автоматический добивающий Laguna Blade и контекстное применение Flame Cloak
- Защитные реакции и перехват линейных снарядов
- Требуется UCZone с включённым Stage 2

## Установка

1. Скачайте `lina-brain-v0.5.173.zip` из <a href="https://github.com/PirucaxD/lina-hero-brain/releases/tag/v0.5.173" target="_blank" rel="noopener">релиза автора</a> и распакуйте архив.
2. Поместите `Lina.lua` и папку `lib` в `umbrella\scripts`.
3. Требуется UCZone с включённым Stage 2; ознакомьтесь с README автора.

# Lina Hero Brain (English)

## What it does

An external Lina project that adds decisions requiring state across ticks and hero-specific knowledge. Its author maintains the source and releases in a separate repository.

- Combos and target selection with killability checks, including defensive modifiers
- Automatic Laguna Blade kill-steal and context-aware Flame Cloak usage
- Defensive responses and line-projectile interception
- Requires UCZone with Stage 2 enabled

## Install

1. Download `lina-brain-v0.5.173.zip` from the author's <a href="https://github.com/PirucaxD/lina-hero-brain/releases/tag/v0.5.173" target="_blank" rel="noopener">release</a> and extract it.
2. Place `Lina.lua` and the `lib` folder in `umbrella\scripts`.
3. UCZone with Stage 2 enabled is required; read the author's README.
