## Что умеет

Модифицированный контроллер вардов, адаптированный для Death Ward Witch Doctor, включая обычную и усиленную с помощью shard версии.

- При включении направляет Death Ward атаковать героя противника с наименьшим здоровьем в радиусе
- Поддерживает обычный Death Ward и версию от shard

## Установка

1. Поместите `witch_doctor_ward_controller.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Настройте `Heroes → Hero List → Witch Doctor → Main Settings → Ward Settings`.

# Witch Doctor Ward Controller (English)

## What it does

A modified ward controller adapted for Witch Doctor Death Ward, including the regular and shard versions.

- When enabled, orders Death Ward to attack the lowest-health enemy hero in range
- Supports both regular Death Ward and the shard version

## Install

1. Place `witch_doctor_ward_controller.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Configure `Heroes → Hero List → Witch Doctor → Main Settings → Ward Settings`.
