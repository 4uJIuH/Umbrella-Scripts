## Что умеет

Небольшой скрипт для Tinker, который применяет Glimmer Cape в выбранный момент применения Rearm.

- использует Glimmer Cape во время Rearm
- находится во вкладке настроек героя

## Установка

1. Поместите `tinker_glimmer_rearm.lua` в `Umbrella\scripts`.
2. Перезагрузите скрипты и настройте его во вкладке Tinker.

# Tinker Glimmer during Rearm (English)

## What it does

A small Tinker utility that activates Glimmer Cape at the selected point during Rearm.

- uses Glimmer Cape while Rearm is active
- available in the hero settings

## Install

1. Place `tinker_glimmer_rearm.lua` in `Umbrella\scripts`.
2. Reload scripts and configure it under Tinker.
