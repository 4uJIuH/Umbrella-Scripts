## Что умеет

Рисует конус возможного Blink от позиции смерти в направлении, куда герой смотрел до гибели. Помимо визуальной подсказки, включает опциональный спам Blink по курсору в коротком окне до и после возрождения; эту функцию можно отключить.

- Визуальный конус направления и дальности Blink
- Настраиваемые угол, цвета и продолжительность показа
- Учитывает Aegis и доступные предметы Blink
- Опциональный бинд спама Blink по курсору до и после возрождения

## Установка

1. Поместите `aegis_blinkout_cone.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `General → Main → Конус блинка после Aegis → Настройки → Общее`.
4. Спам Blink включён по умолчанию; отключите его в настройках, если нужна только визуальная подсказка.

# Aegis Blinkout Cone (English)

## What it does

Draws a possible Blink cone from the death location in the direction the hero faced before dying. In addition to the visual guide, it includes optional cursor-directed Blink spam in a short window before and after respawn; this feature can be disabled.

- Visual cone for Blink direction and range
- Configurable angle, colors, and display duration
- Accounts for Aegis and available Blink items
- Optional cursor-directed Blink spam bind before and after respawn

## Install

1. Place `aegis_blinkout_cone.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `General → Main → Конус блинка после Aegis → Настройки → Общее`.
4. Blink spam is enabled by default; disable it in settings if you only want the visual guide.
