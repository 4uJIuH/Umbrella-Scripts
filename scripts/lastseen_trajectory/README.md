## Что умеет

Отображает направление, в котором противник двигался в последний раз, в игровом мире и на карте. Использует параметры цвета, длительности и размера из настроек серверного скрипта.

- рисует направление последнего перемещения в мире и на миникарте
- поддерживает настройки цвета, времени отображения и размера

## Установка

1. Поместите `lastseen_trajectory.lua` в `Umbrella\scripts` и перезагрузите скрипты.
2. Настройка находится в `Информация → Мапхак → Показывать направление`.

# Last Seen Trajectory (English)

## What it does

Displays the direction in which an enemy was last moving in the game world and on the map. It uses the server script's color, duration, and size settings.

- draws the last movement direction in-world and on the minimap
- supports color, display duration, and size settings

## Install

1. Place `lastseen_trajectory.lua` in `Umbrella\scripts` and reload scripts.
2. Find the option under `Information → Maphack → Show direction`.
