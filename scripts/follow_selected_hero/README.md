## Что умеет

Добавляет следование за союзником, функции поддержки Io, покупки предметов, использование предметов и несколько боевых помощников. Опция чата выключена по умолчанию; при включении скрипт может отправлять объявления и ответы на поддерживаемые команды в игровой чат.

- Следование за выбранным союзником и настройки безопасного перемещения
- Помощники Io: Tether, авто-прокачка, Overcharge и Harass
- Проверка предметов и настраиваемая автоматическая покупка
- Необязательные объявления и ответы на команды через игровой чат

## Установка

1. Поместите `FollowSelectedHero.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Utility → Follow Hero`.
4. Учтите: `Should use chat` включён по умолчанию не будет; активируйте его только если хотите, чтобы скрипт писал в игровой чат.

# Follow Selected Hero (English)

## What it does

Adds ally following, Io support features, item purchasing and usage, and several combat helpers. The chat option is disabled by default; when enabled, the script can post announcements and respond to supported commands in in-game chat.

- Follow a selected ally with configurable movement safety
- Io helpers for Tether, auto-leveling, Overcharge, and harass
- Item checks and configurable automatic purchasing
- Optional in-game chat announcements and command responses

## Install

1. Place `FollowSelectedHero.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Utility → Follow Hero`.
4. Note: `Should use chat` is disabled by default; enable it only if you want the script to post in in-game chat.
