## Что умеет

Автоматически применяет выбранные предметы на себя во время телепортации, чтобы попытаться защитить каст.

- Поддерживает Ghost Scepter, Ethereal Blade, Shadow Amulet, Glimmer Cape, Silver Edge и Shadow Blade
- Можно включить применение на союзников, находящихся в радиусе предмета
- Общий менеджер находится в `Global → Item Manager`; параметры визуального блока — `Info Screen → Main → Heroes Overlay → Main → Show Me TP`

## Установка

1. Поместите `can_teleport_out.lua` в `umbrella\scripts` и перезагрузите скрипты.
2. Откройте `Global → Item Manager` и настройте предметы и применение к союзникам.

# Can Teleport Out (English)

## What it does

Automatically uses selected items on yourself during a teleport channel in an attempt to protect the cast.

- Supports Ghost Scepter, Ethereal Blade, Shadow Amulet, Glimmer Cape, Silver Edge, and Shadow Blade
- Can also target allies within an item's cast range
- The global manager is under `Global → Item Manager`; overlay options are under `Info Screen → Main → Heroes Overlay → Main → Show Me TP`

## Install

1. Place `can_teleport_out.lua` in `umbrella\scripts` and reload scripts.
2. Open `Global → Item Manager` and configure items and ally targeting.
