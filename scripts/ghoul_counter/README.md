## Что умеет

Запускает и останавливает обратный отсчёт с настраиваемым шагом, задержкой и каналом чата.

- Старт и остановка по F9 или выбранному бинду
- Настраиваемые начальное значение, шаг, задержка и канал
- Можно добавить финальное сообщение

## Установка

1. Поместите `ghoul_counter.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте General → Main → Interface → 1000-7.

# 1000-7 Counter (English)

## What it does

Starts and stops a countdown with configurable step, delay, and chat channel.

- Start and stop with F9 or a selected bind
- Configure the starting value, step, delay, and channel
- Optional final message

## Install

1. Place `ghoul_counter.lua` in `umbrella\scripts`.
2. Reload the Lua scripts.
3. Open General → Main → Interface → 1000-7.
