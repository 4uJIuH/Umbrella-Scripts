## Что умеет

Внешний проект для Sniper, дополняющий встроенную обработку героя решениями по убийствам, угрозам и защите. Код и обновления остаются в репозитории автора.

- Оценивает возможность убийства и не тратит ультимейт на цели под защитными эффектами
- Помогает реагировать на угрозы и прерывать длительные каналы
- Требуется UCZone с включённым Stage 2
- Обновляется автором отдельно: после новых изменений архив нужно скачать и обновить вручную
- Лицензия PolyForm Noncommercial 1.0.0 разрешает только некоммерческое использование

## Установка

1. Скачайте `sniper-brain-v6.15.277.zip` из <a href="https://github.com/PirucaxD/sniper-hero-brain/releases" target="_blank" rel="noopener">релизов автора</a> и распакуйте архив.
2. Поместите `Sniper.lua` и папку `lib` в `umbrella\scripts`.
3. Требуется UCZone с включённым Stage 2; следуйте README автора при ручном обновлении.

# Sniper Hero Brain (English)

## What it does

An external Sniper project that supplements the built-in hero handler with kill, threat, and defense decisions. The code and updates remain in the author's repository.

- Checks killability and avoids spending the ultimate on protected targets
- Helps respond to threats and interrupt long channels
- Requires UCZone with Stage 2 enabled
- The author updates it separately; download and replace the archive manually when new changes are published
- PolyForm Noncommercial 1.0.0 permits noncommercial use only

## Install

1. Download `sniper-brain-v6.15.277.zip` from the author's <a href="https://github.com/PirucaxD/sniper-hero-brain/releases" target="_blank" rel="noopener">releases</a> and extract it.
2. Place `Sniper.lua` and the `lib` folder in `umbrella\scripts`.
3. UCZone with Stage 2 enabled is required; follow the author's README when updating manually.
