## Что умеет

Показывает текущую серию убийств и время до её сброса. Панель оформлена в стиле Liquid Glass и может перемещаться по экрану.

- Отображает названия уровней серии: Kill, Double Kill, Triple Kill, Ultra Kill и Rampage
- Показывает оставшееся время 18-секундного окна серии
- Настраиваемые минимальная серия для показа и масштаб панели
- Перемещаемая панель с сохранением позиции и настройкой блокировки
- Можно показывать панель в ожидании новой серии

## Установка

1. Поместите `rampage_timer_h.lua` в `umbrella\scripts`.
2. Перезагрузите Lua-скрипты.
3. Откройте `Scripts → Other → Rampage Timer`.

# Rampage Timer (English)

## What it does

Shows the current kill streak and the time remaining before it resets. The Liquid Glass-style panel can be moved around the screen.

- Displays streak labels: Kill, Double Kill, Triple Kill, Ultra Kill, and Rampage
- Shows the remaining time in the 18-second streak window
- Configurable minimum streak to display and panel scale
- Draggable panel with saved position and a lock option
- Can keep the panel visible while waiting for a new streak

## Install

1. Place `rampage_timer_h.lua` in `umbrella\scripts`.
2. Reload Lua scripts.
3. Open `Scripts → Other → Rampage Timer`.

## Changelog

- Added a kill-streak timer with an 18-second reset window.
- Added a Liquid Glass-style panel with scaling and drag support.
- Added a minimum streak display setting and an idle display option.
